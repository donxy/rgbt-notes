**一句话要点**：JFRDet performs explicit feature-domain affine registration with illumination-guided complementary fusion for severely misaligned visible-infrared pairs; introduces the DVMA severe geometric-misalignment benchmark.

## 点评

「severe」是变换族而非像素量级：其 DVMA 基准由 DroneVehicle 对齐对给 IR 施加旋转 ±(15°–30°)、各向异性缩放 [0.90, 1.10]、平移并仅保留重叠 IoU∈[0.70, 0.80] 的对，偏移空间可变达数十至数百像素，与 OAFA 的原生 0–15px 残差、CF-Deformable DETR 的 ±50px 纯平移不在同一坐标系（且实验输入被 resize 到 480×384，任何像素横比都会误导）。配准机制：以 RGB 为参考，双向注意力粗匹配 → 多尺度局部窗细匹配 → 置信加权最小二乘拟合单一图像级 2×3 仿射 → 逐层 warp 全部 IR 特征；DVMA 留档变换参数生成 GT 对应监督，是同谱系中唯一有配准监督者，但作者从未报告配准精度本身、只以检测 mAP 间接验证。回退只有恒等映射一档（退回未对齐直接融合的自身基线），无单模态第二级防御，触发频率未报告。其两个「reliability」命名都不是模态健康量：一个是纯训练期损失权重调度（限幅 [0.5, 2.0] 倍、下限是减半不是关闭、推理期不存在），一个是整图平均强度这一手工统计量（光照门谱系中最原始的一员），且融合式为纯叠加、IR 无门——没有任何一路能被折扣到零。评测可引用性为同谱系最弱：只有 DVMA 一个基准且训练/测试扰动同分布，无严重度分档、无退化曲线、无零失准对照，证明的是「同分布可学」而非退化平缓；但其表 2 有成套单模对照（C2Former 43.1 < RGB 单模 50.8；IR 单模 mAP50:95 36.0 ≈ 全量 JFRDet 36.1），作者亦明言多加一路不必然改善——几何损伤轴上的旁证，须与内容退化轴分开引用。退化/缺失/故障评测严格为零；RGB 内容损坏时对应与仿射本身先坏、warp 会把完好 IR 证据系统性搬错位置（结构推断）。

## 问题定义

问题被严格限定在几何失准轴，且取该轴的极端一端：可见光–红外对因传感器位置、视角与平台运动存在平移、旋转、尺度差异，多数既有方法只面向对齐或弱失准输入（原文口径：弱失准约 0–5 像素，原基准的天然偏移多在 1–5 像素），大偏移几何差异未被处理。作者另指出一个放大因素：骨干反复下采样会把小幅图像级偏移映射为低分辨率特征图上几乎不可分辨的位移，使弱失准训练实际接近对齐条件，模型学不到真正的跨模几何校正。本文的立场是把显式配准做回管线：先估计图像级仿射变换、在特征域逐级变换对齐，再在对齐特征上融合与检测，配准与检测端到端联合优化。问题设定的边界须注意：两路输入的内容均被假定完好，唯一的病理是位置与姿态错位；且失准全部为合成注入，真实采集链路的天然严重失准分布未测、未统计。

## 方法细节

总体流程：双流骨干提取两模态多尺度特征，以可见光分支为几何参考，跨模态仿射对齐模块（CMAA）估计仿射变换并把红外特征逐级变换到可见光坐标系，光照引导互补融合模块（IGCF）在对齐特征上融合，旋转框检测头输出结果。训练标签取红外模态的标注（因原基准中红外标注更完整），即特征对齐的参考系与检测监督的标注参考系并不一致，原文未讨论这一选择的影响。CMAA 分三步：粗匹配在深层特征上以模态内自注意力与跨模交叉注意力构造双向置信矩阵，取双向对应并过滤低置信者；细匹配在多尺度特征上以局部窗注意力逐级精化对应，并以轻量回归器修正窗口离散化误差；最后对过滤后的对应以置信加权最小二乘拟合单一图像级仿射变换（2×3，6 自由度，含旋转与各向异性缩放），再逐级变换全部红外金字塔特征，变换产生的无效区域在后续计算中掩码。配准带有真值监督：自建基准的变换参数全部留档，可自动生成真值对应，且监督双向对称，映射到有效区外的位置在损失中掩码。回退只有一处：有效对应少于 3 对、或估计变换被判为几何不可靠时，改用恒等映射，即退回不对齐、直接融合的构型；没有单模态检测分支等第二级防御，回退触发频率与不可靠判定细节原文未报告。IGCF 的光照分数是整图统计量（可见光图归一化平均强度，非学习、无标注），空间门由两模态增强响应的差异图预测并被全局暗度标量缩放，最终融合为纯叠加：两路基底特征恒以全额进入求和，门只调制可见光的增强响应项，没有模态级权重，更没有把某一路压至零的通路。对齐质量–一致性门控（AQCG）是纯训练期监督调度：按对齐损失的滑动平均与两类损失关于变换参数的梯度余弦相似度，把检测损失权重调制在 0.5 至 2.0 倍之间（下限是减半而非关闭），推理期不存在。

## 实验设置

唯一基准为作者自建的 DVMA，由无人机车辆检测基准的对齐对派生：可见光图中心裁剪，红外图施加复合变换——旋转正负 15 至 30 度、各向异性缩放（水平与垂直因子独立采样于 0.90 至 1.10）、平移（平移分量的采样范围原文未单独给出），仅保留变换后有效区重叠比例在 0.70 至 0.80 之间的图对，复合变换产生的跨模偏移随位置变化、量级为数十至数百像素，变换参数全部留档以生成配准真值。任务为无人机可见光–红外旋转框车辆检测（五类），指标为 mAP50 与 mAP50:95，所有输入统一缩放至 480×384。关键限制：训练集与测试集的扰动来自同一构造分布，没有按严重度分档的测试子集、没有零失准对照、没有分布外失准测试，也没有随失准量变化的退化曲线。对照方法全部在同一基准上以旋转框头评测，含单模态检测器（可见光与红外各四种）与三种融合方法，单模态对照行齐全。实现基于常用检测框架，双卡训练 12 个轮次；参数量、计算量与推理时延全文未报告。数据量口径在表格与正文之间不一致，引用时须注明所据出处。

## 关键数字

主结果（表 2，DVMA）：本文方法 mAP50 69.7 / mAP50:95 36.1。最强融合基线为 66.7 / 35.1，其余融合方法在 59.5–61.6 / 28.2–31.4 之间。逐类 AP50 上，本文方法在卡车（66.7，次优 58.7）与货车（55.4，次优 50.7）上优势最大；汽车类 87.9 并非最佳，红外单模态检测器的 90.2 更高。单模态对照（表 2）：红外普遍强于可见光，最佳单模态红外为 61.6 / 36.0，最佳单模态可见光为 50.8 / 25.6；值得注意的是，红外单模态的 mAP50:95（36.0）与全量本文方法（36.1）几乎持平，本文方法的增益几乎全部落在 mAP50 这一宽容定位口径上。表中还存在融合低于单模态的行：一种融合方法加两阶段检测头的 mAP50 为 43.1，低于可见光单模态的 50.8，原文亦明确写道，在大的跨模几何差异下，简单引入额外模态并不必然改善检测。组件消融（表 3，mAP50 / mAP50:95）：直接融合基线 66.0 / 34.3，加配准模块升至 67.3 / 34.4，再加融合模块升至 68.0 / 34.8，配准加训练期门控（无新融合模块）为 68.2 / 35.0，全量为 69.7 / 36.1。训练期门控的敏感性分析显示其净贡献约为 1 个 mAP50 点量级，超参网格内结果波动不超过 1.2。

## 消融说明了什么

组件消融表明，增益的真实分解与标题叙事之间有距离：显式仿射配准是标题卖点，但在作者自己的强融合基线之上它只带来 +1.3 mAP50，且 mAP50:95 几乎不动（34.3 到 34.4），即配准主要改善宽容 IoU 下的检出，高精度定位口径的提升要等融合模块与训练期门控齐备后才出现。融合模块与训练期门控单独叠加各约 +0.7 与 +0.9，两者齐加相对仅配准版本为 +2.4，呈超加和，提示两者之间存在协同；但消融设计无法区分训练期门控的增益究竟来自其宣称的机制，还是来自任何形式的损失权重日程（与固定权重日程的对照缺失）。缺失的消融有四处要害：没有配准模块内部消融（粗、细两级匹配各自的贡献、置信阈值敏感性、恒等回退触发率均未测）；没有配准精度本身的评估（基准提供了真值对应与变换参数，完全可以直接报告变换估计误差或对应命中率，全文却只以检测指标间接验证配准）；没有手工光照统计门与学习式光照门的对照；没有严重度分档，方法在更大旋转或更低重叠时何时失效无从回答。另须注意，消融基线本身已高于主表中除最强基线外的全部已发表融合方法，消融参照系与主表不同，两处增益不可混读。

## 局限

内容退化、模态缺失与传感器故障评测为零：全文唯一的病理是几何失准，没有噪声、模糊、过曝等内容退化，没有模态缺失或复制输入对照，没有任何热传感器故障条件；融合模块所称的不可靠可见光响应仅指低光照场景，判据是整图平均强度。失准评测的可引用性有限：与受控协议（测试时逐档注入已知偏移并给出曲线）相比，本文是训练与测试同分布的汇总评测，既无退化曲线也无零失准对照点，所证明的是在该扰动分布上端到端可学，而非失准增大时退化平缓。严重程度的横向比较须谨慎：其严重主要指旋转加各向异性缩放的复合变换，与纯平移口径、原生小偏移口径不在同一变换族与坐标系下，任何像素量级的直接横比都会误导。全局刚性假设方面：单一图像级仿射无法表达视差、纵深相关的局部偏移与非刚性形变，无人机高空近平面场景下近似可辩护，但原文未讨论适用边界，也未在非平面数据上验证，全文只有一个无人机基准。复现性缺口包括：代码与自建数据集在当前版本中仅为将发布承诺，对齐损失的具体构成未给出公式，平移分量采样范围未写明，数据量口径前后不一致，效率数字全缺。
