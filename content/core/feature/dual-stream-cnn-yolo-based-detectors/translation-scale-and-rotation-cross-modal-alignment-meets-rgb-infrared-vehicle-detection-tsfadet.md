**一句话要点**：TSRA module calibrating feature maps for translation, scale and rotation deviations between modalities, plus a modality-selection strategy, in a two-stream detector for DroneVehicle.

## 点评

RoI 级显式有监督几何对齐：两流 FPN 特征经共享 Oriented RPN 出提议，逐提议以旋转 RoIAlign 池化双模态区域特征、直接相减得差异特征，三组 FC 回归平移/尺度/角度共 5 自由度偏差（真值由成对双模态真值框解析计算、smooth L1 监督），再在校正后的提议处重池化。参考模态不固定：由离线标注贴合度打分逐目标选定（训练侧的标注质量量，推理期无真值时如何分配角色原文未交代）。对齐后融合是无条件相加——无门控、无加权、无任何置信/健康量，感知模态恒以 100% 进入；消融总增益 +4.44 全部来自对齐侧。对失准只有自然偏差统计，无受控失准评测（训练期的提议抖动增广不是测试协议）——航拍对齐线的失准鲁棒性从未被受控量测。标注修改规则把可见光极差光照的目标在两个模态中一并删除，最接近单模态严重退化的样本被移出基准而非被评测。数字为 DroneVehicle 验证集 + 作者修改版标注口径：TSFADet 73.06、Cascade-TSFADet 73.90。

## 问题定义

本文的问题是航拍 RGB-IR 图像对的跨模态弱失准（weakly misalignment）：同一目标在两模态中的位置、尺寸、角度同时存在偏差。作者给出的成因分析（§3.1）分两类——硬件误差（辐射畸变改变同一地物的成像表观从而造成尺度/位置差；两传感器时钟偏移使运动目标在两模态中位置/角度不一致）与标注误差（两模态分别标注难以保证同一目标框的一致性），两类可叠加，且三类偏差（位置/尺寸/角度）彼此耦合，不能用单一仿射变换一并解决。量化上，作者对 DroneVehicle 真值框的统计（§4.2、图 8）：以位置/尺寸偏移 3 像素、角度偏移 3 度为阈值，超过 20% 的真值框存在偏差问题。须注意，这里的「偏差」是两个健康传感器之间的几何配准偏差与标注不一致，输入内容本身始终完好；全文没有损坏模态、缺失模态或传感器故障的设定，标题与结论中的 robust 指对弱失准的鲁棒，不是抗腐化。阅读依据：预印本 arXiv:2209.13801v1 全文；ECCV 正式版未逐字比对，章节/公式/图表号均按预印本。

## 方法细节

（1）TSRA 在管线中的位置：第二阶段、提议（RoI）级，不在骨干特征图级。双流骨干（ResNet-50 + FPN，五级特征）各自出特征，两模态特征先做特征聚合，由共享的 Oriented RPN 生成旋转提议；TSRA 在第二阶段对每个提议的两模态区域特征做对齐，之后才进分类/回归头；整体扩展自 Oriented R-CNN 的两阶段框架，MMDetection 实现。（2）对齐过程是显式几何偏差回归，非隐式注意力：给定提议框，先用 rotated RoIAlign 在两流上池化出参考模态区域特征 ϕr 与感知模态（sensed）区域特征 ϕs，两者直接相减得差分表示 ϕd = ϕs − ϕr；三组全连接层分别预测位置偏差、尺寸偏差、角度偏差共五个自由度；把偏差加到提议框得感知提议；再用 rotated RoIAlign 在新位置对感知流重新池化，即得对齐后的感知特征。（3）对齐后的融合算子是无权重的逐元素相加：参考特征 + 在校正提议处重池化的感知特征。没有门控、没有加权、没有置信度——对齐是融合前唯一的跨模态操作，融合本身与基线的简单相加同为一类。（4）监督信号是显式、有真值的偏差回归：总损失在分类、回归与 RPN 损失之外加偏差损失（权重 λ = 1），对正样本提议的位置/尺寸/角度三组预测以 smooth L1 对齐真值偏差；真值偏差由两模态成对真值框解析计算（平移按参考框角度旋转并以参考框宽高归一化，尺寸取对数比，角度取模 2π 后归一化）。因此 TSRA 的可训练性依赖数据集提供逐目标的双模态配对标注。（5）参考模态不固定：MS（Modality-Selection）策略按标注质量逐目标选参考——对每个目标对的两模态真值框打分：把框扩展到完整目标、裁剪、二值化后，按原框内目标像素占目标总像素与占框面积的比例各半加权，分高者为参考框，另一模态为感知模态。须注意这是一个标注侧、离线的量，打分输入是真值框与目标裁剪；论文未交代推理期（无真值）时 MS 如何为提议分配参考/感知角色，此处为原文未明述。（6）Multi-task Jitter（MJ）是训练期合成偏差增广：训练时对感知提议叠加零均值高斯抖动（平移、尺度、角度各一组），设置沿用 AR-CNN 的 ROI jitter，人为放大偏差样本，让偏差回归头学得更稳；这是训练增广，不是评测协议。（7）实现：SGD（momentum 0.9、weight decay 1e-4），20 epochs，batch 6，输入 512×512，初始 lr 0.005 于第 16、19 epoch 各降为十分之一；水平/垂直翻转增广。

## 实验设置

数据集只有 DroneVehicle（28,439 对 RGB-IR 图像）一个，且作者修改了原始标注，三条规则：①只在单模态标注的目标按相同位置补到另一模态；②可见光下处于极差光照的框在两个模态中一并丢弃；③对两模态框排序使同一目标同索引。修改后训练集 17,990 对、验证集 1,469 对；全部结果报在验证集上（非官方测试集），指标为 IoU = 0.5 的 mAP。故本节数字与使用原始 DroneVehicle 标注或测试集口径的论文不可直接同表。对照：单模态旋转检测器 5 个（Faster R-CNN(OBB)、RetinaNet(OBB)、RoI Transformer、S2A-Net、Oriented R-CNN，分别在 RGB 与 IR 上）；多光谱对照为作者在旋转检测框架上复现的 Halfway Fusion(OBB)、CIAN(OBB)、AR-CNN(OBB)，骨干同为 ResNet-50、训练设置对齐。评测足迹核查（全文核查）：只有 DroneVehicle 一个数据集、干净基准、整体 mAP；无昼/夜拆分结果（数据集本身跨昼夜，但只报总 mAP 分类别）；无受控失准评测；无噪声/腐化注入、无模态丢弃或置零、无热成像故障模型。

## 关键数字

均为 DroneVehicle 验证集（作者修改版标注）、mAP@IoU 0.5。主结果（表 3）：TSFADet 73.06（car 89.88 / truck 67.87 / freight-car 63.74 / bus 89.81 / van 53.99）；叠 Cascade R-CNN 头的 Cascade-TSFADet 73.90。多光谱对照：AR-CNN(OBB) 71.58、CIAN(OBB) 70.23、Halfway Fusion(OBB) 68.19。单模态最强为 Oriented R-CNN：IR 65.50、RGB 62.30——航拍口径下 IR 单模态明显强于 RGB 单模态。消融（表 1）：双流 Oriented R-CNN 相加融合基线 68.62 → 仅对齐过程（位置+尺寸+角度三支、无 MS 无 MJ）71.13 → 加 MS（无 MJ）72.36 / 加 MJ（无 MS）72.05 → 全量 73.06。即总增益 +4.44 全部来自对齐侧组件，融合算子始终是相加、未变。偏差分支消融（表 1，无 MS 无 MJ）：仅位置 69.49；位置+尺寸 70.71；位置+角度 70.27；三支全开 71.13——位置是主项，尺寸与角度各再贡献约 +0.6~1.2。MS 策略对照（表 2）：固定 RGB 为参考 71.57；固定 IR 为参考 72.05；随机选参考 72.42；MS 73.06。MS 相对随机选择只多 +0.64——「选对参考」的净值没有摘要语气听上去那么大。速度（表 4）：TSFADet 18.6 FPS（GV100、512×512、batch 1），与 AR-CNN(OBB) 18.2 相当，慢于 CIAN(OBB) 21.7 与 Halfway Fusion(OBB) 20.4。原文两处小不一致（引用以表 3 为准并注出入）：正文称位置+尺寸分支「from 68.2% to 70.71%」，表 1 基线实为 68.62；表 1 的类别列序为 car/freight-car/truck，表 2、表 3 为 car/truck/freight-car，同一数值序列下 truck 与 freight-car 的归属在两组表间互换（mAP 不受影响，本节分类别数字从表 3）。

## 消融说明了什么

（1）增益分解是干净的：基线与全量模型的融合算子同为相加，+4.44 全部可归于「先对齐再相加」这一件事，其中对齐过程本身 +2.51（68.62→71.13），MS +1.23（71.13→72.36 口径）、MJ +0.92（71.13→72.05 口径），三者大致可加。这是「几何配准误差是航拍 RGB-IR 的一阶误差源」的一个定量注脚，与图 8 的超过 20% 偏差框统计互相印证。（2）五自由度里尺寸的边际贡献最大、位置单独修不动：以基线 68.62 为底，仅位置只 +0.87（69.49）；位置+角度 +1.65（70.27）；位置+尺寸 +2.09（70.71）；三支全开 +2.51（71.13），角度在位置+尺寸之上只再 +0.42。位置与尺寸必须联修才有大头收益，与作者「三类偏差耦合」的立论互相印证。（3）MS 的真实量级要小心读：表 2 中随机选参考（72.42）已高于固定 IR（72.05）与固定 RGB（71.57），提示「训练时让两种参考角色都出现」本身就有正则化式收益；MS 的打分机制在随机之上只值 +0.64。（4）消融的边界：全部分支消融在「无 MS 无 MJ」的底座上做，未见对齐模块插到其他检测器/数据集上的可迁移性消融，也未见偏差预测精度本身（如预测偏差 vs 真值偏差的误差）的直接报告——对齐「准不准」只有下游 mAP 一个间接证据。

## 局限

（1）无受控失准评测：全文对失准的量化只有数据集自然偏差的统计（图 8）。MJ 是在训练期对感知提议注入高斯几何抖动的增广手段，评测始终在自然（不可控、未分级）的验证集上进行；没有「测试时注入已知偏移量 → 量测性能退化曲线」这类协议。因此 TSRA 对多大的偏差会失效、偏差-性能曲线形状如何，本文没有答案。（2）退化/缺失评测为零（已核查）：无腐化注入、无整模态缺失、无传感器故障模型；且其标注清洗规则把「可见光极差光照」的目标从两模态标注中一并删除——最接近「一模态严重退化」的样本被从评测中系统性移除而非被评测。（3）对齐机器没有模态健康概念：MS 的分数度量的是标注框与二值化轮廓的贴合度（标注质量），不是任一模态的信号健康度；对齐与融合链路中没有任何质量/置信量。融合式是无条件相加：感知模态贡献恒以 100% 权重进入，不存在衰减或弃权通路。（4）监督依赖成对双模态真值框：偏差真值与 MS 打分都要求逐目标的双模态配对标注，这正是 DroneVehicle 这类数据集需要作者手工修标注（补框、排序、删框）的原因；换到只有单模态标注的数据集，TSRA 无法按原样训练。（5）推理期 MS 角色分配未明述：MS 打分以真值框与完整目标裁剪为输入，论文未说明测试时如何给 RPN 提议指定参考/感知模态——复现时这是必须自行决定的缺口。（6）协议口径：验证集 + 作者修改版标注，数字不可与原始标注/测试集口径混用；Cascade-TSFADet 的 73.90 是其自身在表 3 的数字。作者自陈局限基本为空——结论节只有推广性展望。
