**一句话要点**：Iteratively refines cross-modal fusion using differences between relation maps of the two modalities.

## 点评

「relation-map difference」的代数实质是两模态各自的模态内自注意力图之差（等价于两支路重构特征之差），λ 的参数化逐项源自 Differential Transformer；差分取自同一迭代内两模态之间，「iterative」是把差分特征反馈为下一轮支路输入（权重共享循环展开、固定 4 轮、无收敛判据），正式版 Pattern Recognition 2026，机制层另据官方代码核查。差分引导与可靠性折扣方向恰好相反：差异被构造性地定义为互补信息、经固定增益加性注入另一支路并逐轮放大，一致成分反被当作「共模噪声」减掉；全文没有任何逐模态质量/可靠性量，λ/α/β/µ 全是与输入无关的全局标量——一路损坏时分歧最大的地方恰是证据最坏的地方，该机制会把这份差分放大着灌进干净支路（结构推断，作者无此实验）。结构上不能弃权：即便假想 λ→0，差分反馈仍以系数 1 注入另一支路输出，融合头恒定消费两支路。退化/缺失/故障评测为零。自家表 6（同框架支路头输出、非独立基线）显示基线 IR 头 mAP 47.6 高于融合头 46.9，加本方法后融合头 car 类仍低于 IR 头，作者自承是 RGB 模糊特征被带入融合。迭代消融尖锐非单调（Iter 1 跌破基线、Iter 4 峰值、其后回落），回路无内在稳定机制；头条增益落在 mAP50/总体 AP，FLIR mAP75 不敌 DAMSDet。

## 问题定义

本文处理的是融合质量问题：现有特征融合在合并两模态时保留了两模态共有的背景与冗余，同时把互补的目标线索稀释。作者将其归结为两个挑战——如何在保留显著互补目标特征的同时抑制模态共享的背景干扰，以及如何以不过高的复杂度实现自适应特征整合。解法借用差分放大器的类比：把两模态的共享成分视为共模成分予以抑制，把非共享成分视为差模成分予以放大，再以反馈迭代渐进执行。输入假设始终是干净、配准、成对的可见光–红外图像；文中所称的噪声指特征空间的共享背景冗余，而非传感器层面的噪声，低光、遮挡、复杂背景等仅作为数据集自带场景出现。

## 方法细节

总体管线为双流骨干分别提取两模态特征，每条支路各过一个由互特征精炼模块（MFRM）与差分特征反馈模块（DFFM）组成的闭环并迭代多次，精炼后的支路特征再经 NIN 块汇合，送入检测颈部与检测头。MFRM 中，每模态各自做查询、键、值投影，关系图是本模态的自注意力图；先在值层按可学习标量混合另一模态的值，再以本模态关系图加权重构。标题所称的关系图差分，经公式展开即两模态各自的模态内自注意力图之差（等价于两支路重构特征之差），取自同一次迭代内两模态之间；迭代指的是把差分特征反馈为下一轮的支路输入，定深展开、固定轮数、无收敛判据，各轮权重共享。差分特征的引导方式是加性注入：经多层感知机与层归一化后以可学习增益残差式加回被精炼支路。全部调节量均为训练后固定的全局可学习标量，不依赖当前输入；融合中不存在把任一模态权重压至零的通路，也没有逐模态质量分数或不确定性估计。损失沿用基座检测器的检测损失，对差分与反馈机制本身无辅助损失。

## 实验设置

数据集为 FLIR（三类）、LLVIP（低光行人）与 M3FD（4,200 对、六类），指标为 COCO 风格的 mAP50、mAP75 与 mAP。主框架为双流 Co-DETR 式检测器（双流视觉骨干、特征金字塔颈部与并行检测头，输入 640×640），基线为同一框架的 NiNfusion；另把模块移植到 YOLOv5 上做跨框架验证。主对比表的对照行全部是其他融合方法，没有独立训练的单模态检测器行；与单模态最接近的对照是同一框架内可见光头、红外头与融合头三者的输出，但这些头位于联合训练的双流网络之上，支路特征已经过跨模态模块，引用时需带此口径。全部评测在干净对齐输入上完成，没有损坏、缺失或传感器故障协议。

## 关键数字

FLIR（原文表 1）：本文方法 88.3 / 48.0 / 50.7（mAP50 / mAP75 / mAP），基线 84.8 / 44.0 / 46.9，提升 +3.5 / +4.0 / +3.8；mAP50 为全表最佳，mAP75 的 48.0 略低于 DAMSDet 的 48.1。LLVIP（表 2）：98.4 / 83.1 / 70.9，基线 98.0 / 80.7 / 69.5，mAP50 与 ICAFusion 并列最高，mAP75 与 mAP 为全表最佳。M3FD（表 3）：90.8 / 61.9（mAP50 / mAP），基线 87.1 / 58.2，mAP50 与 ICAFusion 并列，mAP 与 Fusion-Mamba 并列。支路头输出（表 6，FLIR 全类）：基线红外头 mAP 47.6 高于融合头 46.9；加入本文模块后融合头升至 50.7 转为最高，但融合头在汽车类上的 mAP75（67.6）与 mAP（62.2）仍低于红外头的 70.3 与 63.5，原文将此归因于可见光中模糊的车辆轮廓与背景干扰被带入融合。跨框架（表 7）：在 YOLOv5 上 FLIR mAP50 由 79.9 升至 84.8、mAP 由 40.2 升至 43.4。代价（表 9）：YOLOv5 框架帧率由 45.3 降至 17.0、参数量由 75.4M 升至 134.0M；Co-DETR 框架帧率由 3.6 降至 3.1、计算量明显上升。

## 消融说明了什么

模块消融（表 4，FLIR 全类）：仅 MFRM 带来 +1.5 / +2.0 / +1.7，仅 DFFM 带来 +2.7 / +2.0 / +2.3，两者齐备为 +3.5 / +4.0 / +3.8（mAP50 / mAP75 / mAP）。增益高度集中于在两模态中都最弱的自行车类（合并后 mAP50 +9.9），与放大弱互补线索的设计叙事一致；但仅 MFRM 时汽车类 mAP75 反而下降 3.9，原文分析为 MFRM 把可见光中与红外轮廓相似的背景边缘一并放大、损害精确定位，说明无差别放大对高 IoU 口径是双刃的。迭代次数消融（表 5）呈尖锐非单调：1 轮时 mAP 甚至低于基线，随后上升，在 4 轮达到峰值，5–6 轮回落；原文解释为过迭代使差分特征被逐渐削弱、背景成分放大反噬，表明该反馈回路没有内在稳定机制，最优工作点是一个调出的常数。注意力替换消融（表 8）：以普通自注意力或交叉注意力替换后，本文方法在 mAP50 与 mAP 上仍占优，但其 mAP75 是三者中最低，与主表中 mAP75 不占优相互印证，即增益主要落在宽松 IoU 与总体 AP 上。

## 局限

作者自承两点：小目标与重遮挡目标上失效，此时共享线索与差分线索同时变得不可分辨；迭代结构计算成本高，不利于实时与边缘部署。评测面：没有任何退化、缺失或传感器故障评测，主对比表也没有独立单模态对照行，融合结果与单模态检测器的系统比较在其评测体系内未被设置。机制面：差异被构造性地等同于互补信息，但差异同样可能来自某一路的失准或噪声，机制没有任何区分二者的成分，反馈回路会把差异内容以固定增益注入另一支路并逐轮处理；全部调节量都是与输入无关的全局标量，系统对单次输入中哪一路更可信没有表达。另有图面与正文小疵：框图上半两个差分反馈块的支路标注相同（上方一块应为可见光支路）；正文个别增益数字与消融表的归属不完全对齐，引用以表格为准。
