**一句话要点**：Uncertainty-aware alignment resamples visible features onto the infrared reference, and a reliability-guided sparse mixture of experts routes between RGB-dominant, IR-dominant and interaction experts.

## 点评

不确定性感知对齐把可见光特征重采样到红外参考上，可靠性引导的稀疏专家混合在 RGB 主导、IR 主导与交互专家间路由；面向错位 RGB-IR 无人机图像对，MBU 基准 AP50 89.7。

## 问题定义

面向未对齐（misaligned）RGB–红外遥感图像的微小 UAV 目标检测。实际双传感器系统因基线差、镜头畸变、平台振动、云台抖动与异步曝光而难以严格配准；对微小 UAV 而言，几像素的位移就足以把目标响应挪到另一个局部特征区域，直接拼接/相加融合会制造虚假的跨模态对应。作者指出既有工作的两个缺口：(1) 对齐模块在重采样完成后默认对齐结果可信，但小目标周围、遮挡边界、运动模糊与背景干扰处的局部对应仍然不确定；(2) 融合算子多为固定算子或静态注意力，无法适应可靠性随场景与空间位置的变化。因此作者把问题重构为：融合之前先估计“对齐后的局部对应是否可信”，并让这一可靠性估计显式地充当下游融合的路由先验（routing prior）。评测基准为 MBU（Misaligned Bimodal UAV），由 Anti-UAV 双模态跟踪数据抽帧构建，天然包含目标偏移与模态相关的可见性变化。

## 方法细节

两条不共享权重的 YOLOv5s 系（CSPDarknet）分支分别提取 RGB 与红外多尺度特征 {P3,P4,P5}，以红外分支为空间参考（低光下 UAV 目标在红外中更稳定），经 U-TA 对齐与可靠性估计后由可靠性引导的稀疏 MoE 融合，再接 YOLOv5 检测头。(1) U-TA（不确定性感知目标对齐）：偏移预测器估计稠密二维形变场，把可见光特征按可变形采样（双线性重采样）拉向红外参考网格，对齐由目标偏移伪标签监督；与重采样并行，可靠性分支把红外特征与对齐后的 RGB 特征通道拼接、过子网络与 sigmoid，得到逐位置标量可靠性图 R∈(0,1)——高值表示该处对齐对应可信，低值表示失配、遮挡或重采样不稳定。R 无像素级标注，靠自监督损失训练：对齐后两路特征越接近，R 被推得越高，另有对数项防止 R 全零平凡解（默认 λ=10⁻⁴）。注意这一监督本质上是自指的：可靠性由对齐后特征之间的一致性定义，而非由真实偏移误差校验。(2) 可靠性引导的稀疏 MoE 融合分两步消费 R：第一步软门控——对齐后的 RGB 特征先被 R 逐点调制后再与红外特征拼接（红外一路不调制）；第二步专家路由——路由器以调制后的拼接特征为输入（并不直接读 R，可靠性是经调制间接进入路由输入的），softmax 得到 RGB 主导、红外主导与交互融合三个专家的概率，按 top-k 选出后重新归一化加权求和。但在默认配置下硬选择并不发生：默认 k=3 而专家池总共只有 3 个专家，论文在三处明说此时全部专家恒激活，机制退化为对三个专家的输入相关软加权；“稀疏”只是为将来扩增专家池预留的形式。路由权重在训练与推理时以同一规则计算。总损失 = 检测损失 + 对齐损失 + 可靠性自监督损失（默认权重均 1.0），端到端训练，无任何测试时更新。

## 实验设置

单一基准 MBU：源数据 Anti-UAV 含 318 对 RGB–红外视频（训练 160 / 验证 67 / 测试 91 对），每 40 帧抽 1 帧并去除水印区，得到 14,946 张图像（训练 7,530 张 / 7,309 个目标；验证 3,122 / 2,983；测试 4,294 / 4,127），单类别（UAV）；划分与预处理与 MBUDet 协议一致。实现：YOLOv5s 双分支，输入 320×320，batch 16，主实验训练 80 epoch，路由默认 k=3、训练与推理同规则；指标 P / R / F1 / AP50 / AP50:95，以 AP50 为主；本文方法与受控基线均跑 3 个独立种子报 mean±std。对照的组织方式：MBUDet 原始两阶段配方（可见光分支 load-and-freeze 预训练）的 90.1% AP50 及 SuperYOLO、DEYOLO、CFT、ICAFusion 等已发表数字被明确降格为“背景上下文”，不进受控对照表，主证据是同一 YOLOv5s 系协议下复现的基线。唯一的受控压力测试：测试时只对 RGB 一路施加合成平移（红外与标签不动），模拟传感器基线变化与平台抖动，幅度 5 / 10 / 20 / 40 px、每幅度对四方向取平均，与静态融合基线对照。

## 关键数字

主结果（表 1，3 种子）：AP50 89.7±0.2%（三种子 0.895 / 0.898 / 0.899），AP50:95 43.5±1.0，P 96.9±0.5，R 86.5±0.5；参数 12.21M，7.5 GFLOPs。受控基线：YOLOv5s-RGB 80.7±0.9；YOLOv5s-IR 81.2±0.7（红外单模态略强）；Early-Concat 86.7±1.6；Channel Add 86.8±0.8；U-TA Static（对齐 + 静态融合）87.8±0.2；参数匹配静态融合 87.5±0.7——相对最强单模态 +8.5、相对静态对齐融合 +1.9。注意 MBUDet 原配方的 90.1 高于本文 89.7，作者明确不主张“全面最优”，只主张受控协议内的增益。合成移位鲁棒性（表 6）：AP50 增益随移位增大消失——0 px +1.9、5 px −0.1、10 px −0.2、20 px −0.2、40 px +0.0（40 px 时两者同为 85.8）；AP50:95 增益保持为正但同样收窄（+1.4 / +0.6 / +0.7 / +0.4 / +0.3）。实测路由权重（表 7）：三类场景（白天 N=1393 / 暗光 N=242 / 强逆光 N=39）中交互专家权重始终最大（0.378 / 0.379 / 0.385），红外主导（约 0.327–0.332）恒略高于 RGB 主导（约 0.288–0.292），场景间差异极小；目标区平均可靠性仅 0.31–0.34（白天 0.3272、暗光 0.3053、逆光 0.3439）——绝对值偏低，说明 R 未经校准、只能作相对量用。参数匹配对照（表 4）：静态融合加宽到 12.7M 参数 / 8.1 GFLOPs 仍只有 87.5，低于本文的 89.7（12.21M / 7.5G）——增益不能归因于容量。

## 消融说明了什么

组件消融（表 2）把增益拆得很清楚，也拆出一个反直觉结果：以 U-TA Static（对齐 + 静态融合）87.8±0.2 为基线；无可靠性引导的 MoE（有 MoE、无可靠性引导）89.2±0.6——MoE 本身贡献了 +1.4，是增益的大头；只有可靠性、没有 MoE 的版本反而掉到 87.2±0.5，低于静态基线——可靠性调制单独使用是负作用；全模型 89.7±0.2——可靠性引导只有与 MoE 结合才带来额外 +0.5（且与无引导 MoE 的 89.2±0.6 标准差重叠）。top-k 敏感性（表 3）：k=1 / 2 / 3 的 AP50 为 87.59±1.38 / 87.32±0.13 / 87.62±1.13，几乎无差异，作者自承只作配置选择、不作优越性主张。损失权重扫描（表 5）：各权重单因素变化下 AP50 在 87.1–88.1 间波动，不敏感。一处内部不一致：表 3 与表 5 的 AP50 整体落在 87–88 区间，与主表 89.7 对不上，文中未解释，引用其超参结论时应留意。图 4 的“退化条件下专家分配倾向”是作者明示的概念示意（expected tendency），不是实测；实测路由统计只有表 7 的三个自然场景分组。

## 局限

作者自陈：(1) k=3 下执行并未缩减为严格稀疏子集，稀疏激活的计算优势要等专家池扩增后才成立，当前实现还有路由开销、嵌入式部署需核级优化；(2) 合成移位只是受控压力测试，不能替代真实传感器标定变化；(3) 只在 MBU 单一协议上验证，跨平台（机载、地对空、无人机载）泛化未测。据原文事实指出：损坏与缺失模态两者都没有评测——全文唯一的受控扰动是几何错位（RGB 合成平移），没有对任何一路施加噪声 / 模糊 / 低光等光度腐化作为评测，也没有模态丢弃 / 整路清零实验；图 4 与表 7 涉及的暗光、逆光是 MBU 的自然场景类别而非受控退化，只作观察性路由分析。本文的“可靠性”是 对齐后对应的可信度，不是模态健康度——完全对齐的一对图像仍可有一路被腐化，那种情形不在本文的考察范围内。也没有任何“融合不劣于更强单模态”的保证或主张：无定理、无此类表述；单模态臂只在干净 / 对齐条件下报告（RGB 80.7、IR 81.2），在移位压力下连相对静态融合的 AP50 优势都归零，且未在压力条件下与单模态臂对照。退化类型仅合成平移一种（5–40 px、四方向平均），无任何真实热成像故障模型——无条纹噪声、无非均匀性（NUC）漂移、无坏点、无热饱和；也无光度腐化评测。无测试时适应：可靠性图与路由器均为训练时学得、测试时冻结的前向计算。可靠性图自指且未校验：R 由对齐后特征间的 L1 一致性自监督，若两路在同一位置同时出错、或错位发生在无纹理区，一致性高而对应仍可错；MBU 本有目标偏移标签可用于校验 R 与真实偏移误差的相关性，作者未做；R 约 0.33 的绝对水平也表明它未被校准。证据范围：单一数据集、单类别、320×320 输入、UAV 专用场景；补充材料表 S1–S3（种子级结果与训练日志、逐方向移位结果、路由权重 / 可靠性统计汇总）在正文中仅被列为“prepared for submission”，未随 arXiv 版本发布、未能读到，逐方向移位数字与路由日志细节无从核验；“sparse”的命名与 k=3 全激活的实际名实不符。
