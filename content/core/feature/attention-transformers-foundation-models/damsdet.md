## 问题定义

红外–可见光目标检测的两个耦合难题：(1) 互补特性高度动态可变——同一场景内不同目标在两模态中的信息量完全不同（图 1(a) 三个行人分别为：可见光只提供干扰信息、两模态各提供部分信息、两模态都提供完整信息），且随场景与目标逐个变化；已有全局光照权重或框级、ROI 级区域权重粒度太粗，压不住某一路对某个目标是干扰的情形；(2) 模态错位——两模态成像原理与拍摄时刻不同，即使人工配准，同一目标在两图中的位置仍常有明显偏移（图 1(b)），基于对齐假设的融合会破坏特征一致性，而 AR-CNN 式显式对齐需要双模态成对框标注、成本高。作者主张把这两个问题放进同一个模块里逐目标、逐语义层、渐进地解决：先为每个目标选出主导模态的显著特征作查询初始化，再在解码过程中自适应地从两模态多层特征中采样聚合，让错位适应与细粒度互补挖掘同时发生。

## 方法细节

总体结构（图 2）：双 ResNet50 骨干（每模态一条）提取特征，各接一个 RT-DETR 式 Efficient Encoder（1 层）；两模态编码特征拼接后进入 Modality Competitive Query Selection（MCQS）选出初始目标查询；随后 6 层级联 Multispectral Transformer Decoder 以多光谱可变形交叉注意力（MDCA）逐层精化查询与 4D 锚框；最后检测头输出框与分数。MCQS（模态竞争查询选择）：把两模态展平的编码特征序列拼接，过线性层得到每个特征点的分数，在拼接后的联合集合上取 Top-K（K=300）作初始查询。每个被选特征天然只属于一个模态，于是竞争的结果是逐目标实例的：哪个模态的特征分数高，该目标的初始查询就来自哪个模态——在融合早期就避免把另一模态的干扰带进查询表示，给解码器提供这个目标应优先看哪一路的先验。内容查询与位置查询都用此法选出；配合 IoU-aware 分类损失提升所选特征质量，并用 DN-DETR 式去噪训练缓解同一目标在两模态各产生一个冗余查询的问题。MDCA（多光谱可变形交叉注意力）：Deformable DETR 稀疏采样的多模态扩展。对每个查询，先由上一层输出更新 4D 参考框（级联逐层精化）；再以查询特征 + 参考点位置嵌入为输入，用两组线性层分别为两模态预测采样偏移与聚合权重。关键在归一化：权重在模态 × 语义层 × 采样点的联合集合上 softmax 归一（总和为 1）——两模态不是各自归一再相加，而是在同一个池子里竞争采样预算。偏移被约束在 4D 参考框范围内，且两模态各自独立预测偏移，因此错位时两路可分别采到正确的目标位置。语义层数 3、注意力头 8、每层每头采样点 4。动态自适应到底是什么（定向核查）：两处动态性都是由查询内容特征驱动的注意力分配，没有任何显式的模态质量、可靠性、退化估计：MCQS 是目标级的硬选择（查询初始化时选哪一路的特征，只在第 0 步发生一次）；MDCA 是查询 × 头 × 层 × 采样点粒度的软加权，每一解码层重新计算，模态间的此消彼长是联合 softmax 的副产物而非被建模的对象。训练：总损失 = IoU-aware 分类损失 + L1 / GIoU 框损失 + 去噪损失，每解码层加辅助损失；COCO 预训练权重初始化；仅用随机缩放、裁剪、翻转等基础增广——无模态丢弃、无腐化增广。

## 实验设置

数据集（四套，均为干净条件标准协议）：M3FD（4,200 对，6 类；官方无划分，作者按场景自划 3,368 训练 / 831 验证，训练与验证场景相似度低）；FLIR-aligned（4,129 训练 / 1,013 测试，3 类，含昼夜）；LLVIP（12,025 训练 / 3,463 测试，行人类，低光监控，配准良好）；VEDAI（1,200 对，9 类，航空小目标，严格配准，框转水平框）。实现：双 ResNet50 骨干，Efficient Encoder 各 1 层，解码器 6 层，注意力头 8、采样点每头 4、查询 300；输入尺寸 M3FD / FLIR 640×640、LLVIP / VEDAI 1024×1024；学习率 1e-4（VEDAI 2.5e-4）；FLIR / LLVIP 训 20 epoch，M3FD / VEDAI 训 50 epoch；单卡 RTX 3090。指标为标准 COCO AP（mAP50 / mAP75 / mAP）。对照：单模态 YOLOv5 / v7、DINO（IR / RGB / TarDAL 融合图三种输入）与 CFT、ICAFusion、GAFF、SMPD、MFPT、LRAF-Net、MS-DETR、CSAA 等融合方法已发表数字；消融表中另有以本文自身单分支作单模态臂的对照。鲁棒性协议：无。无腐化、噪声注入，无模态缺失、丢弃评测，无受控错位量级扫描（错位仅以数据集天然错位 + 采样可视化定性处理）。依据说明：已取得 arXiv 预印本全文并通读正文 §1–§5、表 1–表 5 与图 1–图 6 图注；版本以 arXiv:2403.00326 v3（2024-03-07）为准——v3 的标题与作者（Guo, Gao, Liu, Meng, Gao，共 5 人）与 ECCV 2024 正式版一致，注意 v1、v2 标题作 DAMS-DETR 且只有 4 位作者（无 Xinbo Gao），v3 才改为现名并补入第五作者；Springer 正式版在付费墙内，与 v3 之间若有个别措辞、数字差异无从核对，下文数字均以 arXiv v3 为出处。

## 关键数字

M3FD（表 1，自划验证集）：mAP50 80.2 / mAP75 56.0 / mAP 52.9，推理 0.117 s。比 CFT（68.2 / 44.6 / 42.5）高 +12.0 mAP50 / +10.4 mAP；单模态 DINO 最好成绩为 RGB 73.3 mAP50、IR 58.8。差距幅度在四个数据集里以 M3FD 最大。FLIR-aligned（表 2）：mAP50 86.6 / mAP75 48.1 / mAP 49.3；此前最好融合方法 LRAF-Net 为 80.5 mAP50 / 42.8 mAP，本文 +6.1 / +6.5。单模态 DINO-IR 有 80.6 mAP50（红外在 FLIR 上强于 RGB 的 70.9）。LLVIP（表 3）：mAP50 97.9（与 LRAF-Net、MS-DETR 并列饱和）/ mAP75 79.1（比次好 MS-DETR 76.3 高 +2.8）/ mAP 69.6（比 LRAF-Net 66.3 高 +3.3）。VEDAI（表 4）：mAP50 91.5 为最好（比 LRAF-Net 85.9 高 +5.6），但 mAP 55.3 反而低于 LRAF-Net 的 59.1——作者自陈小目标框精度对位移敏感、CNN 局部特征提取在 mAP 上占优（见局限）。自身单模态臂（表 5，M3FD）：仅可见光分支 75.7 mAP50 / 49.3 mAP，仅红外分支 62.2 / 38.5——在 M3FD 上可见光分支远强于红外分支；双模态全模型 80.2 / 52.9，在干净条件下高于两个单臂。

## 消融说明了什么

消融在 M3FD 上进行（表 5，9 行配置）：双模态但无 MCQS、无 MDCA（普通查询选择 + 标准可变形注意力作用于两编码器输出相加的融合特征，含内容查询特征选择）为 77.8 mAP50 / 51.6 mAP。MCQS 的贡献：+1.1 mAP50 / +0.7 mAP（77.8 → 78.9），作者归因于早期不引入另一模态干扰；量级不大但方向与其竞争选择叙事一致。MDCA 的贡献：+1.5 mAP50 / +0.9 mAP（77.8 → 79.4）。两模块齐备且含内容查询选择时全模型最好（80.2 / 52.9）；去掉内容查询选择（内容查询改可学习、位置查询仍由 MCQS 给出）只降到 79.3 / 52.6——内容查询选法影响有限，且在单模态臂上影响更小（基本无差异）。图 3 / 图 5 两组可视化是方法叙事的主要定性证据：Top-K 查询确实按目标分布到不同模态；深层解码中采样点与权重向信息量大的模态与低层语义（红外）、高层语义（可见光）分化。注意这些都是自然图像上的观察，不是受控变量实验。

## 局限

作者自陈（§4.5，仅一条）：极端错位处理不了——目标超出 4D 参考框范围时，该模态的目标特征直接丢失（采样被约束在锚框内是 MDCA 的结构代价）。据原文事实指出（非作者原话）：损坏与缺失模态，两者都没有评测——全文没有任何腐化、退化协议（无噪声、模糊、过曝、条纹等注入），没有模态缺失或整路丢弃实验，没有测试时干预；其问题动机里的干扰信息（如图 1(a) 烟雾中消失的行人）指的是自然场景下一路信息天然贫乏，与传感器模态被损坏是两回事，证据也只到采样可视化为止；FLIR / LLVIP 的昼夜、低光是数据集固有内容，不是退化评测。无任何融合不劣于更强单模态的保证或专门分析：干净条件下全模型高于自身单臂（M3FD 80.2 vs 75.7 / 62.2），但无定理、无受压条件对照；且单臂数字来自消融表的自身分支，与主表跨方法单模态基线不可直接混用。无测试时适应：MCQS 与 MDCA 均为训练学得、测试冻结的前向计算。无真实热成像故障模型：条纹噪声、非均匀性漂移、坏点、热饱和均未出现；错位也未做量级受控扫描，MDCA 对错位的鲁棒性只有定性图证。可比性注意：M3FD 用作者按场景自划的验证集，与用官方或其它划分的工作不可直接同表比较；主表对照多为已发表数字而非同协议复现。VEDAI 上 mAP 输给 CNN 方法（55.3 vs 59.1），说明其优势集中在大目标、中高 IoU 区间，小目标框精度是短板。效率：双 ResNet50 + 6 层解码，M3FD 推理 0.117 s 每对（表 1），比 YOLO 系融合方法（CFT 0.050 s、ICAFusion 0.033 s）慢一个量级，属精度优先的 DETR 路线。
