**一句话要点**：Alignment-free DETR whose cross-modal deformable attention maps points between modalities directly.

## 点评

「alignment-free」的机制是无监督的跨模寻址而非对齐：偏移由两模态拼接特征 + 位置嵌入预测、无真值监督（作者自称 unsupervised mapping，仅检测损失与偏好校准引导），在另一模态特征图上逐头采样聚合——与 AR-CNN 的显式有监督逐 proposal 偏移回归正相对照。污染通道从权重层下沉到寻址层（结构推断）：偏移与注意力权重由两模态拼接特征预测，一路内容损坏会直接误导在完好模态上的采样位置。融合属 enhance-only 家族：跨模相关经残差保证本模态 100% 保留、两路无权相加，无任何质量/可靠性量、不能弃权。它有真正的受控失准评测（表 2 固定偏移 {0,5,10,20,30,50}px 逐档扫描，有效半径约 10–20px，50px 时 FLIR 掉至 61.7），但失准全部是把严格对齐原图人工平移红外一侧合成的（FLIR ±10px、LLVIP ±20px），原数据集的天然失准从未测量；旋转/视差/非刚性不在其内。三张主表无任何单模态检测器行（V/IR 两行均为融合头输出，引用须防误读）；严格对齐口径下它输给同组 LRAF-Net，卖点是偏移下的平坦度而非精度。退化/缺失/故障评测为零。

## 问题定义

问题被严格限定为几何弱对齐：可见光–红外对因载体不稳定运动存在像素级偏移，既有融合方法默认严格对齐、在弱对齐数据上性能骤降。作者盘点的既有路线有二：整图逐像素配准（计算代价不可承受）与两阶段检测器内的 ROI 抖动局部对齐（AR-CNN 路线，效率仍不足）。本文的立场是彻底取消对齐步骤：借 DETR 的点式检测思想——参考点聚合若干预测关键点的特征即可完成检测——把「对齐」改写为「跨模态关键点搜索」：一模态上的参考点自动到另一模态上寻找对应关键点并聚合其特征，点映射成立则图像级对齐不再必要。作者自称这是该问题上第一个 alignment-free 的点式检测网络。问题设定的边界须注意：两路输入的内容均被假定完好，唯一的病理是位置偏移；偏移在实验中全部为人工合成（见实验设置），原数据集自带的天然失准既未测量也未统计——三个基准的原始版本在本文中被当作「严格对齐」数据使用。

## 方法细节

整体为编码器–双模解码器–双预测头结构（图 2）：ResNet-50 骨干 + 与 Deformable DETR 同配置的 Transformer 编码器分别提取两模态特征；解码器含三件套——单模可变形注意力 SDAM、跨模可变形注意力 CDAM、点级特征融合模块（正文 §3.1 称 Bimodal Adaptive Fusion Module, BAFM；§3.4 与图 2 称 Point-level Feature Fusion Module, PFFM，指同一模块）；融合特征 FF^v 与 FF^ir 分别送两个检测头，输出两套结果（表中 V / IR 两行）。参考点（object query）数 Q = 300。CDAM 是「alignment-free」的确切机制：先拼后测——把两模态在同一 query 上的点特征通道拼接，经线性层得到融合特征，即跨模偏移的预测输入从一开始就同时含两模态内容；再由融合特征加点位置嵌入经两层线性映射产生无界、无钳制的二维采样偏移；注意力权重按 Deformable DETR 惯例由元素特征与位置嵌入经 Linear + Softmax 产生；最后在另一模态特征图上以参考点加偏移为中心、每头 K = 4 个关键点（H = 8 头，共 32 个采样点）双线性采样并按权重聚合，得到与参考点「已对齐」的跨模点特征。与 AR-CNN 的对照：AR-CNN 是显式、有监督的逐 proposal 偏移回归（真值来自双模配对标注，smooth L1 监督，热红外固定为参考模态，单向对齐）；CDAM 的偏移无任何直接监督——作者在 §3.3 开头自称「the unsupervised mapping by CDAM」，偏移仅靠检测损失与 PFC 一致性损失间接学得，且双向对称（V→IR 与 IR→V 各一条分支）、发生在解码器的点特征层面而非区域/像素层面。SDAM 分支与原版 Deformable DETR 相同，在同模态内采样。PFC 损失是双曲空间的点级一致性：把 SDAM 与 CDAM 产出的同一点双模特征经 Poincaré 球指数映射（曲率 c ≥ 1）送入双曲空间，以类对比形式拉近配对特征；其作用有二：缩小跨模表征鸿沟；引导 CDAM 学出准确的点映射。总损失 = 检测损失 + λ·L_pfc，λ = 0.05。PFFM 融合算子：融合发生在解码器输出的点特征层（query 维度），不在编码器、不在特征图空间维度上——先算跨模相关矩阵（300 个 query 之间的跨模相关，而非空间位置相关），再做残差式相关加权，最后两路逐点相加。全模型没有任何质量/可靠性量：CDAM 的注意力权重是同模态内采样点的含量权重（每头对 K 点 softmax，强制和为 1），PFFM 的相关是特征相似度而非质量估计；残差项保证本模态特征无条件全额保留，两路为无权重相加——结构上不存在把任一模态压到零或折扣的通道。

## 实验设置

数据集：KAIST 用 Liu et al. 改进版，7,601 对训练 / 2,252 对测试；FLIR 用 Zhang et al. 2020 清洗版，4,129 对训练 / 1,013 对测试，尺寸 640×512；LLVIP 共 15,488 对（12,025 训练 / 3,463 测试），1280×1024。指标：FLIR/LLVIP 为 mAP@50 并分 V / IR 两头报告；KAIST 为 MR⁻²（越低越好）。弱对齐数据构造：固定可见光、只对红外图施加随机平移——FLIR 水平/垂直各 [−10, 10] 像素，LLVIP [−20, 20] 像素（按分辨率差缩放）；KAISTw 沿用 Zhang et al. 2019 的构造并额外加入 45° 与 135° 两个偏移方向，得 KAISTw / FLIRw / LLVIPw。偏移的随机种子、每图一偏移还是每集一偏移，正文未交代。受控偏移扫描（表 2 协议）：在上述基础上另行生成固定偏移量 {0, 5, 10, 20, 30, 50} 像素的版本逐档量测——这是人工注入已知偏移的受控评测，与 AR-CNN 的受控协议同类（但档位更粗：6 档，且正文未注明该扫描的偏移方向）；此扫描未用于 KAIST。实现：RTX A6000；ResNet-50 骨干；60 epoch、batch 4、Adam，初始 lr 1e-4、第 40 epoch ×0.1；Q = 300；λ = 0.05。对照来源口径不一，须注意：表 5（KAIST）的所有对照数字引自各原文（正文明示）；表 6/7（FLIR/LLVIP）的对照为作者用公开代码复现。三表均无单模态检测器对照行（无 VIS-only / IR-only）；CF 自身的 V / IR 两行是两个融合头的输出，不是单模结果。

## 关键数字

CDAM 消融（表 1，FLIRw，mAP@50）：完整 CDAM V 77.0 / IR 77.1；用同模坐标直接取跨模点（SDAM 式映射）降至 70.7 / 70.9（约 −6.3）；两阶段映射变体 CDAM⁻（先找跨模参考点再找关键点）最差，63.3 / 63.1，作者归因于点选择的误差累积。受控偏移曲线（表 2，mAP@50）：FLIR（V 头）偏移 0/5/10/20/30/50 px → 77.2 / 77.1 / 77.0 / 73.2 / 67.5 / 61.7；LLVIP（V 头）同档 → 95.0 / 95.0 / 94.9 / 94.8 / 92.2 / 80.7（IR 头几乎同值）。即 ≤10 px（FLIR）/ ≤20 px（LLVIP）近乎无损，超出后单调下滑，50 px 时 FLIR 已掉 15.5 个点——作者亦承认过大偏移因关键点搜索变难仍有负效应，图 4 可视化显示偏移增大时采样点逐渐偏离目标。KAISTw 稳定性（表 5，MR⁻²，引用口径）：CF 的 V 头在无偏移 O 与四方向偏移下为 7.13 / 7.14 / 7.17 / 7.14 / 7.17，IR 头 7.11–7.17，曲线几乎水平；对照中 ProbEn 为 7.66 → 7.57–8.32，AR-CNN 为 8.26 → 8.91–9.79，Halfway Fusion 为 25.51 → 28.30–36.71。但注意 LG-FAPF 在无偏移点为 5.76，优于 CF 的 7.13，只是偏移下退化至 8.55–10.23——CF 赢的是平坦度而非绝对精度。严格对齐 → 弱对齐（表 6，FLIR，mAP@50，复现口径）：CF 77.2 → 77.0（V 头，IR 头 77.1 → 77.1）；严格对齐方法集体塌陷：LRAF-Net 80.5 → 69.9、CFT 77.7 → 68.3、Yolo-FS 76.6 → 67.8、ProbEn 75.5 → 72.8、MBNet 72.4 → 69.3。关键事实：LRAF-Net 在严格对齐 FLIR 上以 80.5 高出 CF 的 77.2 达 3.3 个点——CF 的卖点是偏移下不掉，而非干净数据精度。LLVIP（表 7，mAP@50，复现口径）：CF 95.0 → 94.8（V 头）；LRAF-Net 97.9 → 93.2、CFT 97.5 → 93.0、ProbEn 95.5 → 93.7、MBNet 94.8 → 93.1。同样，严格对齐下 LRAF-Net 的 97.9 高于 CF 的 95.0。速度（表 8，FLIR，ms/img）：CF 79.7；AR-CNN 120.0、MBNet 70.9、ProbEn 846.9。免去配准确实比两阶段 AR-CNN 快，但略慢于 MBNet，「高效」仅相对成立。PFC 消融（表 3/4，FLIRw）：双曲空间 PFC 77.0 / 77.1 vs 欧氏空间 76.4 / 76.5（+0.6）；λ 扫描（表 4）λ = 0 时 75.1 / 75.0，λ = 0.05 最优 77.0 / 77.1，λ = 1 回落至 75.2 / 75.2——PFC 整体贡献约 +1.9（对 λ = 0）。

## 消融说明了什么

表 1 说明点映射的学习方式是性能主体：同坐标硬取点（SDAM 式）证明「不找对应点不行」（−6.3），两阶段映射（CDAM⁻）证明映射必须单步端到端、级联搜索会累积误差（−13.7）；但消融集里没有「去掉 CDAM、只留双 SDAM + PFFM」的行，故 CDAM 相对「完全不做跨模采样」的净贡献未被隔离。表 2 是全文最有信息量的消融：它给出可变形采样对偏移的有效半径——约 10–20 px 内近无损、50 px 时明显失效，且失效模式（图 4）是采样点被带偏而非权重失灵，即偏移搜索本身是瓶颈。表 3/4 说明 PFC 的作用是二阶的：双曲 vs 欧氏只差 0.6，λ 从 0 到 0.05 的 +1.9 才是主要部分，且 λ 过大反噬检测损失——一致性约束与检测目标存在竞争。表 5–7 的横向对照共同说明一件事：本文的增益本质是以严格对齐精度换偏移鲁棒性（干净口径下输给 LRAF-Net 3.3 / 2.9 个点），这一交换在作者叙事中未被点明。缺失的消融：无 PFFM 单独消融（相关矩阵融合 vs 简单相加未对照）、无采样点数 K / 头数 H 敏感性、无单模态下限行。

## 局限

评测边界为零外扩：除几何偏移外，退化、缺失、传感器故障评测全部为零——无损坏模态、无缺失/复制输入对照、无条纹/非均匀性/坏点/饱和等热成像故障模型；「鲁棒」仅指对合成平移的鲁棒。失准全是合成的：训练与测试的弱对齐均来自对「严格对齐」原图的人工平移（仅平移红外、仅刚性平移，无旋转/尺度/视差场/非刚性形变）；真实采集链路的天然失准分布未测、未统计，方法对真实弱对齐的泛化由构造保证而非由证据保证。偏移上限也只探到 50 px 且已明显退化。无单模态对照、无下限概念：三张主表没有任何单模态检测器行，无法判断偏移或（假想的）损坏条件下融合是否仍优于丢弃一模态；双头 V / IR 输出容易被误读为单模结果，引用时须注明其均为融合特征。偏移无监督、无约束：采样偏移由线性层直接输出，无幅值钳制、无真值监督、无收敛/正确性验证手段；映射错了只能从检测指标间接发现。PFC 损失式按刊印形式仅有正样本项，与其所引对比学习框架的对应关系含混。公式层面的含混：按融合公式字面推导，两路融合特征为同一张量，表中 V / IR 两行的微小差异只能来自两个独立参数化的检测头；正文未澄清两路融合特征的区别。另外融合模块双名并存、个别符号一符两用，均为 IJCAI 短文的粗糙处。KAIST 口径：表 5 对照数字全部引自原文而非同环境复现，且 CF 的 MR⁻²（约 7.1）与表 6/7 的 mAP 口径不可互换；KAISTw 的每方向偏移幅度沿用 AR-CNN 设定、正文未重述具体像素数。
