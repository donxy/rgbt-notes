**一句话要点**：Independent DETR-style branches for RGB and thermal exchange selected high-quality queries (Query Fusion) between refinement stages, balancing complementarity against modality separation.

## 点评

全队列中耦合最弱的设计：两个完整独立的 DINO 检测器，骨干/编码器/解码器/检测头全部分开、全管线零特征融合，唯一耦合是解码器各阶段之间对离散 (query, proposal) 集合的交换（按置信度 top-k 竞争 + MLP 适配器投影，末端 NMS 合并）；出自 Tian 2025 同组（哈工大深圳）。它确实评了「退化」，但协议只有全损一档——把一路对比度降至零，与缺失端等价：单类型、单档位、仅 mAP50，无分级损坏与传感器故障，是「以缺失充退化」的又一例。全损下其生存性能与幸存分支单机水平几乎重合（FLIR TIR-only 78.6 vs 单机 78.7），是「融合不劣于丢弃一路」在全损端迄今最干净的近似实证；但作者自制的朴素盒级融合相对保持率反而更好，说明优雅退化来自决策级独立性这一结构属性、非其机制独占；作者未陈述或证明任何下限保证。唯一「质量」量是各分支自身的 proposal 置信度（自指），top-k 硬竞争只在受损分支安静地低分时能将其整批排除——「受损但高置信地出错」这一核心失效模式恰被其全损协议绕开、未测。代价是两个完整检测器（96M 参数）+ 两阶段重训；峰值性能不领先，且两数据集均用随机 80/20 划分、无 LLVIP 结果。

## 问题定义

问题被表述为模态失衡下的互补与分离之争：常规条件下融合应利用跨模态互补信息；极端条件下某一模态质量过差、其噪声经融合污染检测，此时应优先模态分离。作者明确指出，若失衡只在测试时出现，检测器面对的是分布外挑战，融合性能可能低于单模态检测器，这是其立论起点。既有方法或紧耦合两模态（对失衡敏感）、或高度分离（牺牲互补），本文要在两者间取得平衡。需注意其退化的操作化定义很窄：实验中唯一的退化形式是将一路模态的对比度降为零，即整模态失效，与缺失情形等价；不存在部分损坏、噪声、模糊等中间形态。

## 方法细节

解耦发生在整机层级：框架由两个完整、独立的 DETR 类检测器（均为 DINO）组成，可见光与热红外各占一支，骨干、编码器、解码器、检测头全部独立，全管线没有任何特征级融合。两支之间唯一的耦合发生在解码器各阶段（共 6 层）之间，交换的对象是离散的查询与提议集合。查询融合分两步：先把两支的提议并集后按各自检测头给出的置信度分数取 top-k，得到两支共享的融合提议集；再由每阶段一对不共享的轻量 MLP 适配器，把对方模态的查询投影到本支分布，以保持分支独立性。随后每支以自己的图像特征、融合查询集与共享提议集独立完成下一阶段解码与预测，最终两支输出合并后做非极大值抑制。全文唯一的质量相关量就是提议自带的置信度分数，由各分支自己的检测头产生，没有外部质量估计器或可学习门控；选择是硬性的跨模态 pooled 竞争，一支的查询可以整批落选。每支本身都是完整的单机检测器，一路模态缺失时另一支可单独运行。训练分两阶段：先两支各自用单模态图像单独训练，再在配对对齐图像上联合微调（骨干与编码器冻结），两阶段循环重复。

## 实验设置

数据集为 FLIR（采用重新配准、重新标注的版本，640×512）与 M3FD（1024×768），两个数据集均按随机 80/20 划分（非官方划分，跨论文比较时须注意），未用 LLVIP 与 KAIST。指标为 COCO 风格 mAP 与 mAP50。主表对照含单模态 DINO 的可见光行与热红外行，以及 GAFF、CFT、ICAFusion 等融合方法。退化评测只有一组协议：将一路模态的对比度降至零以模拟失衡，设双模态正常、仅可见光（热红外失效）、仅热红外（可见光失效）三列，仅报告 mAP50 及相对跌幅；对照为基于 DINO 的三级融合基线（图像级、特征级、框级）以及 YOLOX-RGBT 与 RDMI。退化只有这一种类型、一个全损档位，无分级严重度，无噪声、模糊等部分损坏条件。

## 关键数字

FLIR 主结果（表 1）：本文方法 43.8 mAP / 83.1 mAP50，参数量 96M（即两支单机之和）。单模态 DINO 为可见光 32.6 / 68.6、热红外 41.8 / 78.7，本文方法较最佳单模态 mAP 高 2.0；融合方法中 IGT 为 43.6 / 85.0，本文方法 mAP 仅微胜 0.2，mAP50 反而低 1.9。M3FD 主结果（表 1）：55.9 mAP / 90.4 mAP50；FusionMamba 的 mAP 更高（61.9），mAP50 更低（88.0）。退化保持（表 4，FLIR，mAP50）：本文方法由 83.1 在热红外失效时降至 68.0（相对 −18.2%）、在可见光失效时降至 78.6（−5.4%），与单机 DINO 的 68.6 与 78.7 几乎重合，即全损条件下其表现与幸存分支的单机水平基本一致；对照中 YOLOX-RGBT 由 75.5 降至 40.1 / 43.3，呈双向大幅下降。同一表中，朴素的框级融合基线相对保持率反而更好（79.2 在两种失效下分别为 69.2 与 79.2）。M3FD 上（表 4）本文方法由 90.4 降至 84.9（−6.0%）与 83.4（−7.7%），框级基线的相对保持同样更好。非配对数据实验（表 3）：换入用更多单模态图像另行训练的双支后，FLIR 由 42.3 升至 43.8，M3FD 由 48.9 升至 55.2。

## 消融说明了什么

消融（表 2，FLIR）给出四条结论。其一，仅双分支加输出合并并不成立：无适配器、无第二阶段联合训练的两支组合为 41.7 mAP，甚至略低于热红外单支的 41.8，说明把两个检测器并排运行并合并输出并不自动优于最佳单模态，增益来自后续组件。其二，增益可分解：加入阶段专属适配器升至 42.7，再加第二阶段联合训练升至 43.6，调整训练与测试的 k 值至 43.8；适配器须逐阶段不共享，共享时拟合更差。其三，后处理是承重环节：把非极大值抑制换成 Top-300 截断，性能降至 31.1 / 55.1，说明两支的重复输出必须靠该合并环节去重，融合收益有相当部分经由这一决策级合并实现。其四，k 的绝对值几乎不影响性能，起作用的是训练与测试 k 的相对大小，选择机制的计算开销可压得很低。

## 局限

退化评测只有一个二值端点：对比度降零等价于整模态失效，没有分级损坏；尤其没有评测模态仍在场、内容受损但仍产出高置信错误提议的情形，而在该情形下，以自身置信度为唯一选择信号的 top-k 机制完全可能把受污染的查询选进融合集并经适配器注入另一分支。保持率并非本文机制独有：同一协议下朴素框级融合的相对保持更好，说明全损下的平稳退化主要来自决策级独立性这一结构属性，查询融合的净贡献主要体现在峰值性能一侧。峰值性能不具压倒性：FLIR mAP50 低于 IGT，M3FD mAP 明显低于 FusionMamba；代价是两个完整检测器（96M 参数），且全文未报告计算量与推理时延。第二阶段联合训练仍需配对且对齐的数据。文本疏漏两处：M3FD 上 DINO 两条单模态行数字完全相同，疑为笔误；实现细节所称骨干与图表所标骨干不一致。随机划分也削弱了与采用官方划分文献的可比性。
