**一句话要点**：Drone-based benchmark of deliberately misaligned visible-thermal pairs with a baseline detector, quantifying misalignment sensitivity.

## 点评

无人机未对齐可见光-热红外检测基准（2,179 对原生失准图像，双传感器视场角/分辨率不同、未经对齐后处理），但失准量级全文从未量化：无像素/角度偏移统计、无严重度分档、无合成注入、无随偏移变化的性能曲线——作为失准基准，其对失准的刻画弱于 AR-CNN 的受控偏移协议与 TSFADet 的自然偏差统计。标注每对共享一份、且只标注两模态共有的目标，单模态独有目标不进评测，而失准恰在画面边缘最严重。基准自家表格即有负融合：Add / CMX / CFT 三种融合在 DVTOD 上全部低于最佳热红外单模态（79.2 / 81.6 / 82.7 vs 84.4），CVC14 上同型；只有自带对齐的 CMA-Det 以 +0.6 / +1.6 微弱越线，增益大头是对齐止损而非融合变鲁棒。CMA-Det 的「形变场」实为每层特征图一个 4 参数全局仿射（对齐无几何监督、误差从未被测量），BFCFM 的校正是增益恒 ∈[1,2] 的残差放大——只能增强、不能抑制，末端仍是无条件相加。16 个挑战属性（雨/雪/烟雾/过曝/玻璃遮挡等）只用于划分均匀性、从不分层报告；退化/缺失/故障评测为零。本注记据作者自存终稿（figshare 开放版）全文。

## 问题定义

本文的问题设定须先钉死：它针对的输入缺陷是几何失准（同一目标在两模态中位置与尺度不同），不是内容退化——两路传感器全程健康、内容完整，只是没对齐。问题分两层：（1）数据集层——既有可见光–热红外数据集几乎全部建立在手工对齐（或分光镜硬件对齐）的图像对上，而真实部署中双传感器视场角不同、无人机振动、温度致硬件形变使图像对天然弱对齐甚至失准；配准算法又慢且会失败，缺一个原生失准的基准。（2）方法层——既有融合检测器都假设输入已对齐，失准使对应位置的双模态特征不匹配、精度下降甚至训练难收敛；需要在检测器内部做特征级对齐，而不是依赖外部配准。DVTOD 是首个以“未对齐”为第一性卖点的无人机可见光–热红外检测基准 + 配套对齐基线 CMA-Det，与已对齐的 DroneVehicle、精细对齐的 RGBT-Tiny 形成对照。全文没有模态损坏、模态缺失、传感器故障的议程：雨雪雾、过曝、玻璃遮挡等只是采集场景的多样性设置（场景级协变量），不是受控退化协议。注：本笔记据作者自存终稿（figshare 开放版）全文通读；期刊版为 IEEE Transactions on Intelligent Vehicles, vol. 9, no. 11, pp. 7449–7460, 2024。

## 方法细节

（基准类：此节为基准构建与基线方法。）采集：平台为 DJI MAVIC 2 Enterprise Advanced——热红外为非制冷氧化钒微测辐射热计（640×512，像元间距 12 μm，波段 8–14 μm）；可见光为 1/2 英寸 CMOS（4800 万像素，视场角 84°，视频分辨率 1920×1080，等效焦距 24 mm，f/2.8）。两路以原始状态成对保存，不做任何对齐后处理——失准的来源就是双传感器视场角与分辨率不同（1920×1080 对 640×512），同一目标在两图中的位置与尺度都不同。失准的量级与形态：全文对失准只有一句定性描述“中间畸变小、两侧畸变大”（§III-D），这与其视场角差异/镜头畸变的成因自洽；全文没有任何失准量的统计（无像素偏移的均值/分布、无角度量、无按目标位置的偏移曲线），也没有人工合成失准、失准程度分级或随偏移量变化的性能曲线——基准里只有一个自然失准分布，且其强度不可复现地报告。规模与构成：2,179 对图像（4,358 张）、6,142 个标注目标、3 类（person、car、bicycle）、54 个采集场景，跨全天时段与四季；平均每对不足 3 个目标，场景偏稀疏。属性体系：4 大组共 17 个子属性（除正常光照外 16 个挑战属性）——光照变化（过曝、正常、傍晚弱光、暗夜、路灯、无人机灯光）、天气（雨、雪、人造烟雾模拟雾）、目标多样性（多目标、小目标、快速旋转/运动造成的模糊目标）、遮挡（树木、塑料、雨伞、玻璃、同类间遮挡），属性可重叠；其中过曝（环境温度与人体温度接近、person 在热红外中与背景趋同）与玻璃遮挡（热红外成像质量差）是真实的物理性模态失效场景，但都只是采集时碰到的场景、不是注入协议，且属性只用于划分时保持分布均匀，评测从不按属性分层报告。数据裁剪：从视频序列中人工挑选图像对（保证同一场景内目标或背景有足够差异，避免训练/测试间近重复帧）——是去冗余筛选、不是按难度删样本，但标准是人工判断、未量化，复现性弱。标注（§III-C）：每对图像共享一份标签，常态在热红外图上标注，特殊场景（特殊材料遮挡、过曝致热红外失效）改在可见光图上标注——标注所在的坐标系随场景切换；关键规则是“只标注两模态共有的目标”，因分辨率/视场不同而只出现在一个模态中的目标不标注——这一条与失准的空间形态叠加后果不小：失准在图像边缘最严重，而边缘正是单模态独有目标最常出现的位置，基准在构造上把失准最极端的受害样本排除在评测之外（原文未讨论）。基线方法 CMA-Det：以 YOLOv5（CSPDarknet-s 骨干）扩展的双流检测器，热红外为参考模态、可见光为待对齐模态，三级处理——OSR（跨模态注意力校正：以参考特征与待对齐特征构建自相关/互相关矩阵，扩大可见光特征的有效搜索范围，并以自注意力增强参考特征）；SFAM（特征匹配器对两路经 OSR 校正的特征直接相减得差异特征，送 AffineNet 回归四个全局参数 (x, y, w, h)——位置偏移与尺度缩放——构成仿射变换矩阵、生成 warp 场后重采样可见光特征；须注意摘要说的“形变场”在实现上是每层特征图一个全局仿射（STN 式），不是逐像素稠密形变场，也不是逐目标回归；且没有任何几何监督——数据只有共享单标签，AffineNet 只能靠检测损失端到端学，对齐质量从未被直接测量，只有下游 mAP 做间接证据）；BFCFM（先通道级校正：双路特征各自 avg/max 池化后拼接过 MLP + sigmoid 拆出两路通道权重，校正式为 F′ = F + C·F——增益恒在 [1, 2] 的残差放大，只能增强、不能抑制；再空间级 MLP 加权去噪；最后两路特征直接相加输出——整个融合没有模态级权重、没有健康量、没有任何一路能被压低或弃权的通路）。损失就是 YOLOv5 的三项（GIoU 回归 + 交叉熵分类 + MSE 置信度），无对齐专用损失、无不确定性建模。参考方向按数据集翻转：DVTOD/LLVIP 上热红外作参考，CVC14 上改用可见光作参考、热红外作待对齐模态（原文陈述，未给选择原则）。

## 实验设置

划分：按场景划分 1,606 对训练 / 573 对测试，并保持类别与属性分布均匀；无验证集。指标：PASCAL VOC 式标准 mAP（AP50 口径；CVC14 的表 3 显式标 AP50 并同时给 P/R，DVTOD 的表 2 只标 mAP、未另注阈值）。三个数据集（DVTOD、CVC14、LLVIP）只报全集聚合数字，无任何按属性、按光照、按位置（中心/边缘）的分层结果。基线构成：DVTOD 上 5 个单模态 YOLO（v3/v5/v6/v7/v8，各以可见光、热红外分别评测）+ 3 个双模态方法（YOLOv5+Add、CMX、CFT），作者以相同配置自行复现；CVC14 上比 YOLOv5、CMX、CFT；LLVIP 上的对比数字直接引自各方法原论文（原文明示），且 LLVIP 用的是“未更新版本”数据——三个数据集的数字来源口径并不一致。实现：PyTorch，SGD，400 epochs，batch 12，YOLOv5 的 COCO 预训练权重初始化，单卡 RTX 3060；CMA-Det 参数量 33（表 6 原文单位 MB）、123 FPS（RTX 3060）。

## 关键数字

DVTOD（表 2，mAP）：可见光单模态全线低迷——YOLOv3/v5/v6/v7/v8 为 34.5 / 33.4 / 38.1 / 30.6 / 35.3；热红外单模态为 82.7 / 82.8 / 84.4 / 77.8 / 83.3（YOLOv6 最高 84.4）。双模态：YOLOv5+Add 79.2、CMX 81.6、CFT 82.7、CMA-Det 85.0（person 90.3、car 81.6、bicycle 83.1）。这张表里藏着全文最重要的事实：三种现成融合方法（79.2 / 81.6 / 82.7）全部低于最好的热红外单模态（84.4），Add 甚至低于其同骨干的热红外单模态 YOLOv5（82.8），CMX 数值上亦然——在自然失准数据上，朴素融合不如直接丢掉可见光；只有自带对齐的 CMA-Det 以 +0.6 的微弱 margin 越过单模态天花板。可见光单模态的低分则要打折看：大量夜间/弱光对 + 标签锚在热红外帧，两项都系统性压低可见光口径。CVC14（表 3，AP50）：YOLOv5 热红外单模态只有 38.7（P 51.4 / R 46.4）——该数据集标注在可见光帧、双模态位置/尺度差异大，热红外单模态被帧间错位直接打穿；可见光单模态 82.6；Add 80.7、CMX 68.9、CFT 78.2 三种融合全部低于可见光单模态；CMA-Det 84.2（P 84.3 / R 76.1），仅超可见光单模态 +1.6。LLVIP（表 4，AP50，引自各原论文）：CMA-Det 97.1，高于 UA-CMDet 96.3、ECISNet 95.7、YOLOv5 热红外 94.6、MBNet 93.2、YOLOv5 可见光 90.8、Faster R-CNN 热红外 93.7 / 可见光 89.0——这是已对齐数据上的数字，只能证明对齐模块在对齐数据上不捣乱，不能当作失准鲁棒性的证据；且转引口径与前两表不同源。

## 消融说明了什么

消融只在 DVTOD 上做（表 5，mAP）：Baseline（=YOLOv5+Add）79.2 → +SFA 82.2（+3.0）→ +OSR 83.5（+1.3）→ +BFCFM 85.0（+1.5）。说明三点：（1）增益大头在对齐而不在融合——单个 SFA 就拿走总增益（+5.8）的过半，与 TSFADet“增益全部来自对齐侧”的消融结论同型：失准场景下瓶颈是几何错位，不是融合算子设计。（2）消融的基线本身就是负融合点：Baseline 79.2 低于热红外单模态 82.8/84.4，整条消融曲线是在“先把被失准打坏的融合修回来”的区间里爬坡，终点 85.0 相对最佳单模态的净增益只有 +0.6——消融证明的是“对齐能止损”，不是“融合有大额正收益”。（3）没有对齐质量的消融：无预测偏移 vs 某种真值的误差统计（数据里也没有这个真值）、无按失准大小分档的消融、无合成偏移扫描——因此“对齐模块在多大失准下失效”这个最该由失准基准回答的问题，本文没有给出任何曲线。

## 局限

（1）失准未量化、未分级（已核查全文）：唯一的失准表征是“中间小、两侧大”一句定性描述，没有偏移统计、没有严重度分档、没有受控注入协议。与 AR-CNN 在 KAIST 上合成 [−6,6]² 像素偏移并量测退化曲线、TSFADet 至少给出 DroneVehicle 自然偏差统计（>20% 真值框偏移 >3 px / >3°）相比，DVTOD 作为“失准基准”反而是三者中对失准刻画最弱的一个：它提供了失准的数据，却没提供失准的量尺，后来者无法按失准程度分层比较，也无法复现其失准强度。（2）无退化/缺失/故障评测（已核查全文）：没有模态丢弃、没有内容腐化注入、没有干净–损坏配对、没有热像仪故障模型（条纹/NUC/坏点/饱和均未出现）；16 个挑战属性是场景级协变量且从未被用于分层评测——连现成的过曝（热红外物理性失效）与玻璃遮挡子集都没有单独数字，属性体系实际上只服务于划分均匀性。（3）标注规则系统性排除最难样本：只标双模态共有目标，使“只在一个模态可见”的目标（视场差异 + 边缘大畸变的典型受害者）不进评测；标注坐标系又随场景在热红外/可见光之间切换，协议细节未展开——基准测的是“共有目标在失准下的检测”，比真实失准部署问题窄一圈。（4）规模与多样性有限：2,179 对、6,142 个目标、3 类，量级比 DroneVehicle（56,878 图）与 RGBT-Tiny（93K 帧）小一到两个数量级；单一机型单平台采集；人工挑选图像对的标准未量化。（5）基线方法的形式化弱点：全局仿射（4 参数）对“中心小、边缘大”的空间非均匀畸变在表达上先天不足，文中未讨论；对齐无几何监督、无对齐误差报告；BFCFM 的校正是只能放大不能抑制的残差增益，融合末端仍是无条件相加。（6）数字口径参差：DVTOD/CVC14 为作者复现、LLVIP 为转引且用未更新版数据；表 2 的 mAP 未注 IoU 阈值；表 1 把 DVTOD 分辨率印作 1090×1080，与正文 §III 采集参数 1920×1080 不一致（应为笔误，本笔记以 §III 为准）。
