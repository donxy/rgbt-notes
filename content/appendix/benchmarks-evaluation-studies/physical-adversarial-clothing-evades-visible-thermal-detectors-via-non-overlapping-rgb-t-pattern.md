**一句话要点**：Physical adversarial clothing whose visible and thermal patterns do not overlap (NORP), jointly optimised on a 3D RGB-T human model, with fusion-stage ensembling improving transfer to unseen detectors.

## 点评

物理对抗服装：衣服上每处位置只能二选一呈现——印花织物（可见光任意图案、热辐射≈体温）或低发射铝膜（可见光被钉死为铝膜实测色、热辐射低），non-overlapping 让每个模态都以完整材料强度呈现，离散选择与连续变量强耦合（无 SRD 时攻击成功率从约 100 跌到 46–88）。数字世界中一件衣服对早/中/晚融合（Prob-E/M/L）与双单模态 YOLOv11 的 ASR 齐平于 98.8–100.0（平均 99.6%）；物理世界晚融合 Prob-L 的 ASR 79.2 反为全表最高、高于单模态的 61.2 / 64.4——融合没有任何可测的鲁棒性红利（旁证口径：各检测器精度不同、物理服装的优化目标正文未交代，不是受控反例）。迁移跨融合阶段显著不对称：晚融合优化的图案迁到早/中融合有 92.8 / 94.6，早融合优化的图案迁到晚融合只剩 11.2、迁到单模态约 1.0；集成图案最难打的黑盒是带跨模态对齐的 AR-CNN（76.4，其余 94.8–99.0）。这是腐化谱系的对抗端点：腐化是目标局部的、双模态协同优化的，丢弃任何一路仍剩一路被污染的证据，与自然传感器退化须明确分开引用。引用纪律：物理表 4 中 Clean 普通衣的 ASR 已有 9.4–19.6，须以 Clean 为基线读；正文表 4 与补充材料表 S2 的白盒对角元不一致、两表关系原文未说明。正文与补充材料均已通读。

## 问题定义

问题不是检测精度，而是 RGB-T 检测器的物理世界安全性。作者的出发点：多模态融合检测器通常被默认“相对鲁棒”，其安全性长期被忽视；而单模态物理攻击无法直接搬用——可见光与热红外成像机制差异太大，为一路设计的图案在另一路根本不呈现（§1、§2.2–§2.4）。此前真正做过可见-热双模态物理攻击的工作（AdvB、MAP、MIC、UAP）有两条硬伤：（1）视角窄——AdvB、MAP、UAP 都是 2D 贴片，只在约 −30°~30° 视角内有效；（2）叠层代价——MIC 的重叠式图案（ORP）把多片低发射（low-E）薄膜贴在印制织物之上，薄膜使透光率下降 30%，可见光图案先天被削弱且制作成本上升。攻击目标形式化（§3.1）：对目标 x，要求检测器 f 在阈值 q 下检不出穿衣者。威胁模型：攻击者制造并穿着一件实体服装；优化阶段对目标检测器为白盒（梯度穿过检测器与渲染器），之后把同一件衣服迁移到未见检测器上做黑盒评测。攻击须同时满足三点：全视角 0°–360°、数字与物理双世界、对四类融合架构（早/中/晚融合 + 独立双检测器）都有效。目标行人在干净输入上被各白盒检测器以 0.85 以上置信度检出（§4.2），即攻击对象是“本来检得很好”的目标。问题的内在难点是 NORP 的物理排他约束：衣服上每个位置只能属于一种材料——选铝膜则该处 RGB 被钉死为铝膜实测色、不可再当连续变量优化，反之选织物则该处热辐射只能是体温；离散的材料选择与连续的 RGB 变量强耦合（§3.3），这是必须发明 SDCO 的根本原因，也是这件衣服区别于一切数字扰动与 2D 贴片之处。须与自然传感器退化明确区分：这里的“腐化”是目标局部的、双模态协同梯度优化的对抗构造——丢弃任何一路，剩下的一路仍是被污染的证据，不存在“健康的幸存模态”；且腐化只占目标局部，整图级的模态质量信号会被大面积干净背景稀释。注：本笔记正文（CVF 官方开放版，§1–§6、表 1–表 5、图 1–图 5）与官方补充材料（§1–§12、表 S1–S4、图 S1–S8）均已通读。

## 方法细节

（1）3D RGB-T 人体与服装模型（§3.2）：为在数字世界仿真全视角攻击，先把公开的 3D RGB 人体/服装模型扩展为对齐的 3D RGB-T 模型——把网格面片展开为 2D faces map 并分区（后背、手臂等），用 FLIR T560 实拍服装热图、经变形微调与多角度拼接与 faces map 对齐，得到对齐的热纹理“皮肤”，再用 PyTorch3D 把 RGB 与热纹理贴到同一网格；因服装热特性随时间与地点变化，共采集 10 套人体热纹理，建成昼/夜 × 室内/外四种热服装模型，优化与测试时随机切换；渲染时可见光随机取点光/方向光/环境光，红外固定为环境光并提高亮度以模拟人体热辐射。（2）NORP 参数化与物理约束（§3.3）：图案共 N 个像素，二值变量逐像素选材料——印制织物处 RGB 任意可印、热强度采样自人体热纹理；铝膜处 RGB 与热强度四量全被材料实测常数钉死。non-overlapping 是关键有三层原因：其一，ORP 把 low-E 膜叠在印花之上、透光降 30%，可见图案先天被削弱，NORP 让每种材料以完整强度呈现自己模态的图案；其二，材料便宜常见（普通织物 + 0.1 mm 铝膜）；其三，排他约束本身制造了优化难点（见问题定义）。（3）SDCO 优化（§3.4）：直接对连续松弛变量与 RGB 联合梯度优化效果差——离散化近似会污染 RGB 梯度，反之亦然。空间离散-连续优化的核心是空间随机离散化（SRD）：每轮迭代用 Bernoulli(α) 随机掩码把一部分像素当场离散化（二值化材料选择、冻结其热变量梯度、转而优化对应位置的可见变量），其余像素保持连续可训练、冻结其可见变量梯度；掩码逐轮重采样，使每个像素期望上被两组变量轮流更新，终步统一二值化。实验取 α = 0.7——补充材料给出机理：α 太低则热模态可训练参数远多于可见模态、优化偏向热模态，太高则反之，0.7 时平均 ASR 最高（逐点数值只在曲线图中、未列表，引用时以其文字结论为准）。（4）渲染、贴图与损失（§3.5–§3.6）：优化后的双模态纹理先过 EOT（对物理扰动做期望变换），经渲染器贴到服装网格、与 3D 人体模型合成，再贴到 FLIR-aligned 的对齐背景对上送检测器；损失就是检测器对穿衣者的目标置信度本身（取检测输出中的最高检测分数），最小化之；数字评测的渲染采样为方位角 0–360°、俯仰 −10°~20°、距离尺度 1.5–3.5。（5）融合阶段集成（§3.6）：为让一件衣服同时攻击不同融合架构并提升黑盒迁移，把早/中/晚融合与独立检测器四类损失加权求和（权重为经验值），联合优化同一套纹理。（6）物理实现（§3.7）：织物按优化纹理印制 RGB 图案，须贴膜处在织物上印“X”标记；裁缝把印花织物加工成上衣 + 长裤，再把 0.1 mm 厚铝膜贴入标记区；实物上每像素为 25 mm × 25 mm。（7）优化设置（补充材料）：学习率 0.01、batch size 2；Prob-E/M/L 训练 10k 步、YOLOv11 训练 20k 步；数字图案像素粒度 10×10；RTX 3090、约 20 GB 显存，每 10k 步约 5 小时。

## 实验设置

数据：FLIR-aligned（4,129 对训练 / 1,013 对测试的对齐 RGB-T 图像对）。本文不训练检测器，只把测试集图像对当作 3D 仿真的背景：将渲染出的穿衣人像贴到背景对上评测。白盒目标检测器（§4.2）：早融合 Prob-E、中融合 Prob-M、晚融合 Prob-L（均为 ProbEn 系概率集成检测器在三个融合阶段的变体），以及独立检测器 YOLOv11(RGB)、YOLOv11(T)；作者称这些检测器对干净 RGB-T 行人的检测置信度均在 0.85 以上，是强基线。黑盒目标检测器：早融合 RPN-E、中融合 AR-CNN、晚融合 RPN-L、独立 D-DETR(RGB) / D-DETR(T)（正文迁移实验，表 5）；补充材料另单列 Transformer 检测器 Deformable DETR 专项与两个较新的检测器 E2E-MFD（早融合）、DAMSDET（中融合）。指标（§4.3）：ASR（Attack Success Rate）= 未被检出的目标行人数 / 目标行人总数，越高攻击越强；判定 IoU 阈值 0.5、置信度阈值 0.6；所报 ASR 为跨视角、距离、场景条件的平均。数字评测采样：视角 0–360° 每 18° 取样、距离 2.5–20 m 每 2.5 m 取样（§4.5）。对照方法：Clean（纯色图案）、Random（未优化的随机 RGB-T 图案）、MAP、MIC、UAP——后三者的图案按各自原论文与发布代码复现。物理实验（§4.8）：5 名志愿者（经 IRB 批准），2–4 人一组，分别穿对抗衣、随机图案衣、普通衣，或手持 UAP 贴片；iPhone 13 Pro 与 FLIR T560 同步拍摄可见光与热图像，场景含室内外、晨/午/午后/黄昏，角度 0–360°、距离 2–15 m；共录 116 段视频、以 1 fps 采样得 5,220 对图像；物理对照只有 Clean / Random / UAP——MAP 与 MIC 因 low-E 膜等特殊材料难以实物复现被排除。防御评测（§4.10）：8 种防御——5 种传统方法（Adversarial Training、Total Variance Minimization、Bit Squeezing、JPEG Compression、Pixel Mask）+ 3 种检测攻击专用方法（PAD、NAPGuard、Jedi）。

## 消融说明了什么

（1）SRD 是 SDCO 的胜负手（表 2）：w/o SRD = 78.6 / 88.4 / 67.2 / 48.2 / 46.4，w SRD = 100.0 / 100.0 / 99.8 / 98.8 / 99.4；去掉 SRD 后受损最重的是两个单模态列（46.4 / 48.2）与晚融合（67.2）——即天真联合优化会系统性地偏向一侧模态、把另一侧的图案优化坏；SRD 的随机空间离散化本质上是给离散/连续两组变量强制轮换的优化预算，作者的解释（§4.6）是 SRD 有效平衡了双模态变量的优化。（2）优化器对比（表 3）：同一问题换通用离散-连续优化器——Gumbel-Softmax = 78.6 / 87.8 / 60.0 / 34.0 / 22.6，STE = 95.6 / 96.8 / 94.4 / 92.4 / 86.8，均不及 SDCO；作者的归因（§4.7）是 Gumbel 与 STE 把连续优化与离散操作放在不同阶段（训练/推理、前向/反向），SDCO 则在不同空间区域同时进行，与 NORP 变量的空间分布对齐——这个对照说明 NORP 的难点不在“离散变量存在”，而在离散选择与连续变量逐像素同位纠缠。（3）α 扫描（补充材料）：α 是两模态优化预算的平衡因子，过低则热模态可训练参数显著多于可见模态、优化偏热，过高则反之，α = 0.7 时平均 ASR 最高，实验即取 0.7；逐点数值只在曲线图中，未列表。（4）图案像素尺寸（补充材料表 S1）：5×5 / 10×10 / 15×15 / 20×20 四档，10×10 最优（100.0 / 100.0 / 99.8 / 98.4 / 98.2）；过细（5×5）时融合三列几乎不降（99.8 / 99.6 / 99.2），但独立检测器两列跌到 86.4 / 85.6；过粗（20×20）普遍回落（晚融合 97.0、独立列 87.0 / 88.4）——即粒度折中主要由单模态检测器一侧决定。（5）距离与角度（§4.5、图 4）：在 0–360° 全角度、2.5–20 m 全距离上对四类架构保持高 ASR；对照的先行方法只在约 −30°~30°、3–6 m 内有效——作者把这一差距归因于 3D 建模仿真覆盖的角度/距离范围，而非图案本身，即全视角能力来自评测与优化管线，不来自某个图案技巧。

## 局限

（1）作者自陈的局限（补充材料）：以牺牲服装感知自然性（naturalness）为代价换取攻击效果，与早期单模态工作取舍一致；未来工作是在保持多模态攻击效果的同时提升图案自然度。正文没有独立的局限节，伦理声明在补充材料（技术双刃、应谨慎使用）。（2）白盒目标实质上是“一家三架构”：早/中/晚融合全部来自 ProbEn 同一工作的三个变体，独立检测器是同一 YOLOv11 的两路，“跨融合架构”的证据强度受此限制；黑盒面更宽（RPN 系、AR-CNN、D-DETR，补充材料又补了 D-DETR、E2E-MFD、DAMSDET），但全部实验只在一个数据集（FLIR-aligned）的背景与行人设定上，任务是单类行人逃逸，未触及 LLVIP / M3FD / KAIST 等其他 RGB-T 基准或车辆等其他类别。（3）表 4 的服装归属未交代（引用雷区）：正文与补充材料都没有写明物理主表（表 4）中“Ours”一行的成绩出自哪件（些）衣服——是逐检测器白盒优化的五件分别测，还是集成优化的一件通测，无从确认；且表 4 与补充材料表 S2 的白盒对角元数值不一致（如 Prob-L：79.2 vs 78.4；YOLOv11(RGB)：61.2 vs 表 S2 的双模态平均 66.9，口径亦不同），两表的采集批次关系原文未说明——表 4 不能严格读作“同一件衣服”的跨检测器成绩。（4）物理基线不干净：表 4 中 Clean 普通衣的 ASR 已有 9.4–19.6%，即实拍条件下检测器对正常穿着者本就漏检一至两成；71.0% 的物理平均里含这部分非攻击贡献，攻击的真实增量应以与 Clean 的差值读（约 +45~+64 个百分点，因列而异）；物理对照还缺 MAP / MIC（材料原因未复现），物理世界实际只与 UAP 做了强弱对比。（5）防御评测多在纹理/仿真层施加（补充材料）：Adversarial Training 是往 FLIR-aligned 里加 200 张渲染对抗图微调检测器 10 个 epoch；Pixel Mask 是在衣物纹理上随机挖 80×80 区域、同时移除两路图案；Bit Squeezing 是把纹理从 8 bit 降到 7 bit；TVM / JPEG 作用于纹理；PAD / NAPGuard / Jedi 的开源代码作用于“模拟人”——因此表 S3 的降幅是这一协议下的数字，不是真实穿着场景中部署防御后的实测 ASR，正文“防御后 ≥70%”引用时应连带这一限定。（6）数字到物理的落差未分解：数字平均 99.6% → 物理主表 71.0% → 物理迁移（表 S2）白盒对角 66.9–87.8、黑盒低至 27.4–75.1；落差来自材料实测常数的误差、渲染-实拍差距还是拍摄条件，原文没有做归因分解。（7）一处小口径出入：补充材料表 S1 中 10×10 行的独立检测器两列为 98.4 / 98.2，与正文表 1 的 98.8 / 99.4 不一致（融合三列一致），原文未说明原因；引用独立检测器数字时以表 1 为准并注明此出入。
