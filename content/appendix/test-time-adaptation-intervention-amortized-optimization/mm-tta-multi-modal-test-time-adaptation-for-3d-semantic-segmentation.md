**一句话要点**：Extends test-time adaptation to multi-modal 3D semantic segmentation: intra-modal pseudo-labels and inter-modal pseudo-label refinement, the two modalities regularising each other.

## 点评

它是伪标签去噪、不是模态可靠性处理：测试时只更新两分支的 BN 统计与仿射参数（<1%）、转导式适应、无源数据。其所谓模态可信度是同一模态内慢/快两套 BN 快照预测之间的对称-KL 一致性（逐点计算，用于跨模态伪标签的逐点选/加权）——慢/快模型权重相同、只差 BN 统计，某模态被系统性污染但两快照一致地错时该量保持高位、错误伪标签照常入选；且集成伪标签又把两分支拉向同一目标，受损模态的错误会反向污染健康分支的 BN 更新。全程没有对输入模态健康度的任何估计，融合算子（双分支 softmax 平均）从未被改动，Hard Select 只是逐点二选一、不是逐样本模态弃权。评测全是数据集级域偏移（传感器换型、昼→夜、合成→真实），同分布地作用于整个目标域：无注入、无档位、无模态丢弃，两路始终在场；其最强场景昼→夜恰建立在「LiDAR 光照不变、永远有干净教师」的非对称前提上，与热红外自身可故障的情形正相反。它把「多模态 TTA 已存在、只是没人搬到 RGB-T 检测」的说法钉死为结构性错位：其逐点选择依赖标定投影给出的逐点跨模态对应（检测的稀疏框集没有）、作用对象是决策级双分支（单个中融合检测器里没有可供选择的双分支预测）、处理的是域级统计漂移而非样本级损坏在场——与 CD-Buffer（单模态检测 TTA）恰好构成 2×2 空位图，检测 × 多模态一格仍空。

## 问题定义

TTA 设定（沿 TENT）：测试时只能访问源域预训练模型与无标签目标（测试）数据，不能访问源数据；适应预算为对目标数据过一遍（one epoch）。要解决的问题是：多模态模型在传感器配置、光照、合成/真实等域偏移下性能下降，而把单模态 TTA（熵最小化等）逐分支直接套用会产生训练不稳定——熵最小化使各分支输出分布各自变尖、跨模态差异反而放大，最终集成变差（§1、§3.2；表 1 中多个 TTA 基线的集成 mIoU 甚至低于 Source-only）。关键界定：本文处理的是数据集级的分布偏移（domain shift），不是样本级的模态损坏。三个评测场景（传感器换型、昼→夜、合成→真实）中，偏移作用于整个目标域的所有样本；没有任何一个实验注入受控损坏、设置损坏档位，或区分「模态受损」与「模态缺失」——两路模态在全部实验中始终在场且持续输入。任务为多模态 3D 语义分割，输入是 RGB 图像（2D 分支）+ LiDAR 点云（3D 分支），输出为逐点语义类别。据作者自述，这是多模态 3D 语义分割的第一个 TTA 框架。

## 方法细节

骨干沿用 xMUDA 的双流框架：2D 分支为 U-Net（ResNet-34 编码器），3D 分支为稀疏卷积 U-Net（SparseConvNet 或 MinkowskiNet）；2D 特征在投影后的 3D 点位置采样，故两分支输出天然逐点对齐（均为逐点预测），最终结果为两分支 softmax 平均（late/决策级融合）。适应只更新 BN 参数：遵循 TENT，只估计/优化两分支 BN 层的统计与仿射参数，占参数量 <1%，其余权重冻结；无源数据、无目标标签，逐 batch 在线更新，慢模型跨 batch 以指数滑动累积。两个模块。其一，Intra-PG（模态内伪标签生成）——慢/快双 BN 统计模型：每个模态维护两套 BN 统计，快模型直接用当前测试 batch 的统计替换（激进、最新）；慢模型以动量 λ 对快统计做指数滑动平均（λ=0.99 最优），初值取源模型统计。两模型权重完全相同，只差 BN 统计。慢/快预测取平均后 argmax 得模态内伪标签；推理时只用慢模型。其二，Inter-PR（模态间伪标签精修）——以模态内自一致性做逐点选择/加权：先算每模态的慢-快一致性，即同一模态内部两个 BN 快照预测之间的对称 KL 型相似度，逐点计算。注意：它度量的是同一模态内部两个快照之间的一致性，不是两模态之间的一致性，更不是输入质量的估计。然后两种变体：Hard Select——逐点取一致性较高的那个模态的伪标签；Soft Select——以归一化后的一致性为权重对两模态预测概率加权求和再 argmax；一致性最大值低于类别阈值（0.3 最优）的点被丢弃。适应目标：两分支同时以同一个跨模态集成伪标签做标准分割交叉熵自训练——监督信号是伪标签层面的跨模态互教，而非特征或权重层面的模态重加权；模型本身的融合方式（softmax 平均）不被改动。作者先行检验的基线目标包括逐分支熵最小化、跨模态 KL 一致性损失、朴素伪标签自训练及其组合，结论是一致性损失在无标签时可能被错误分支拖坏，熵与伪标签基线能提升单分支但集成反降。

## 实验设置

三个域偏移场景（§4.1，指标均为 mIoU，分别报告 2D / 3D / Softmax avg 三列）。其一，A2D2 → SemanticKITTI（传感器换型）：源域相机 2.3MP + 16 线 LiDAR，目标域 0.7MP 相机 + 64 线 LiDAR——硬件规格差异造成的双模态同时偏移。其二，nuScenes Day → Night（光照偏移，非对称）：LiDAR 为主动传感器、对光照近似不变；RGB 在夜间颜色分布剧变，挑战被作者明确定位为「如何提升 2D 分支并获得有效集成」。其三，Synthia → SemanticKITTI（合成→真实）：相机风格差 + LiDAR 点分布/深度精度差，双模态同时偏移；Synthia 点云由其深度真值随机采样像素构建。对照：UDA 方法 xMUDA、xMUDA-PL(offline)（可访问源+目标数据、无预算约束，仅作参照）；TTA 基线 TENT、TENT-Ens、xMUDA（一致性）、xMUDA-PL 及其与 TENT 的组合。所有方法同一框架/骨干、各自调参取最优，适应统一为目标数据 1 epoch、测试时用 batch 统计。评测协议性质：全部为自然数据集间偏移，无受控损坏注入、无严重度分档、无模态丢弃/置零实验、无传感器故障模型（无 LiDAR 丢线/点稀疏化、无图像噪声/模糊扫描）。

## 关键数字

主结果（表 1，mIoU %，列序 2D / 3D / Softmax avg）。A2D2→SemanticKITTI：Source-only 37.4 / 35.3 / 41.5；MM-TTA (Soft) 43.7 / 42.5 / 47.1，(Hard) 43.3 / 42.4 / 47.0。对比最强 TTA 基线集成仅 43.0（xMUDA-PL+TENT-Ens）；但 UDA 的 xMUDA-PL(offline) 集成 49.1、3D 单支 48.5 仍高于本文——TTA 预算下未追平可访问源数据的 UDA。Synthia→SemanticKITTI：Source-only 21.1 / 25.9 / 28.2；MM-TTA (Soft) 31.5 / 30.0 / 35.1，与 UDA xMUDA-PL(offline) 的 35.3 基本持平。nuScenes Day→Night：Source-only 42.2 / 41.2 / 47.8；MM-TTA (Soft) 44.2 / 43.7 / 51.8，集成值反超 UDA xMUDA-PL(offline) 的 50.8（§4.3 作者特别指出）；增益结构符合预期——3D 分支变化小（41.2→43.7），主要增益在 2D 分支与集成。基线失效证据（表 1）：A2D2 与 Synthia 两场景中，全部 TTA 基线的集成 mIoU ≤ Source-only 集成（A2D2：40.2–43.0 vs 41.5，其中 TENT 40.8、xMUDA 40.2 为净负；Synthia：27.8–29.7 vs 28.2）——单模态 TTA 直接拼到多模态上在这两个场景系统性失败，这是本文问题动机的量化支撑。伪标签质量（图 5）：适应过程中伪标签准确率，慢-快建模比只用快模型高约 2 个百分点，两模块齐用再高约 5 个百分点。稳定性（图 4）：4 组学习率下集成 mIoU 的均值/标准差——MM-TTA Hard 44.2/2.45、Soft 44.3/2.55；TENT 36.9/3.45；xMUDA 25.8/14.1（一致性基线对学习率极端敏感）。

## 消融说明了什么

表 2（A2D2→SemanticKITTI，Softmax avg）：只用快模型伪标签自训练为 40.8（低于 Source-only 41.5）；加慢模型（Intra-PG）为 41.9——慢-快聚合本身带来约 +1.1，且在 Merge 变体下同样成立（无慢模型时 Merge+选择掉回 41.6，有慢模型时 45.3），说明慢模型是全框架的承重件。简单跨模态融合不够：Consensus（只取两模态一致点）41.8，加选择 43.8；Merge（概率均值）加选择 45.3——均明显低于完整 Inter-PR 的 47.0/47.1；一致性驱动的选择比「只用一致点」更有效，因为它逐点保留了单模态独有的正确标签。选择准则对照：以预测熵代替慢-快一致性做模态选择得 43.4，低于一致性的 47.0——在本文设定内，慢-快一致性是比单模型熵更可靠的逐点可信度代理。伪标签阈值不可或缺：加阈值过滤带来 +2.0。敏感性（表 3）：类别阈值 0.3 最优（0.1–0.7 区间内波动约 ±1）；慢模型动量 0.99 最优，动量 1.00（慢模型冻结为源统计）为 46.3/46.5、0.95 为 46.1/46.3——慢模型必须动、但必须动得慢。消融共同说明的机制图景：增益主要来自监督信号的去噪（慢-快时间集成 + 一致性过滤/选择），而不是来自任何对模态输入本身的可靠性建模；框架没有动过融合权重、没有估计过输入质量。

## 局限

其一，偏移类型与损坏脱节：只评数据集级域偏移（换传感器、昼夜、合成→真实），全部样本同分布地偏移；没有受控损坏、没有档位、没有单样本级损坏，更没有传感器故障（条纹、坏点、丢线、饱和一类）。对「某一路模态在此刻此样本上坏了」的情形，本文协议不提供任何证据。其二，可靠性信号是自指的：慢-快一致性是同一分支两个 BN 快照之间的一致性。若某模态被系统性污染但快/慢模型一致地错（两者权重相同、只差 BN 统计，污染足够稳定时两者很容易一致），该量保持高位，Inter-PR 会照常选中甚至加权该模态的错误伪标签；没有外部锚点校验「一致 ≠ 正确」。其三，无隔离/弃权机制：适应目标把两分支拉向同一个集成伪标签——受损模态的错误标签会反向污染健康分支的 BN 更新；Hard Select 是逐点全量二选一，不是逐样本的模态级弃权，框架不存在「本样本放弃某模态」的表达；两路同时退化时互教信号整体退化，框架无防线。其四，适应是转导式（transductive）、成 epoch 的：需要目标测试集整体可及、顺序过一遍并跨 batch 累积统计；不是逐帧在线、对单个损坏样本即时反应的机制，慢模型的稳定性依赖偏移在整个目标域内平稳。其五，任务结构依赖：Inter-PR 的逐点选择/加权以「两分支对同一组点、同一标签集逐点对齐的稠密预测」为前提（靠标定投影实现），且融合本身是决策级 softmax 平均；对没有逐点对应、输出为稀疏集合的中融合检测器，模块没有可作用的载体。其六，正文未报告适应速度/显存等部署成本；补充材料未随正文提供，Synthia 点云构建等细节只按正文转述、未直接核读。
