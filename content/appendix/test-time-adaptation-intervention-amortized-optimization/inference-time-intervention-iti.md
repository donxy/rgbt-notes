**一句话要点**：Shifts selected attention-head activations along probed directions at inference.

## 点评

全名 Inference-Time Intervention: Eliciting Truthful Answers from a Language Model（NeurIPS 2023 Spotlight，LLM 真实性语境）。干预形式：只对线性探针验证精度最高的 top-K 个注意力头，在其输出上沿探针学到的「真实方向」平移 ασ（强度以每头自身激活标准差归一化）；探针以带真/假标签的问答对在末 token 激活上逐头训练，头集、方向、强度全部离线定死。它与「任务约束局部干预」的最深分界是无触发器：干预对每个输入、每个 token 无条件恒定施加（甚至可烘焙进 bias 项离线固化），全程没有「当前输入是否需要干预」的判别器，其监督信号在部署前即已耗尽——与「默认不干预、由测试时跨模态证据条件触发」恰相反。其判据与失败模式不在一个层面：它治的是「正确答案已编码在内部、只是没说出来」（探针—生成鸿沟约 40 个百分点），受损模态的问题是证据本身被污染、不存在藏着的正确答案等被引出（前提不可迁移）。两件可迁移的零件：稀疏选址是成表实证的承重设计（全头干预与逐点选择都输给按头选择——干预位置稀疏化本身是保住其余行为的前提）；它用 KL/CE 量化干预的附带漂移、并以目标量自身尺度归一化强度，分别对应「对干净样本的扰动量」报告与干预强度校准形式。作者自承它远不足以保证真实回答、强度无理论指导只能试错、沿任何方向平移都不可避免扭曲其他编码信息。

## 问题定义

全名 Inference-Time Intervention: Eliciting Truthful Answers from a Language Model。它处理的问题是「知道 vs 说出」的鸿沟：用线性探针分类中间层激活的精度（probe accuracy）与模型实际生成的精度（generation accuracy）之间存在系统性落差——作者报告 LLaMA-7B 在 TruthfulQA 上两者相差约 40 个百分点（§1）。即模型内部已经以线性可读的形式编码了「这句话是真是假」，但输出不兑现。ITI 的目标是在不微调任何权重的前提下、于推理时把激活沿「真实方向」平移，缩小这一鸿沟。两点边界须先钉死：其一，「真实」被操作化为 TruthfulQA 的字面定义——避免常见人类误解/迷信（817 个问题、38 个子类），作者明言该数据集不可能覆盖「真」的全部含义（§3.1）；其二，这不是鲁棒性问题：输入分布不变、传感器无损坏、模型权重无缺陷，被干预的是模型的行为倾向，不是被污染的证据。领域定位为 LLM 可解释性 / 激活编辑（activation editing），与 RGB-T 检测没有任何任务交集；它收录于附录「Test-Time Adaptation, Intervention & Amortized Optimization」组，是「推理时干预」这一极的源头样本——收录理由是命名与概念对照（inference-time intervention 与 local intervention 同属一个命名家族），不是方法相关性。

## 方法细节

探针定位（离线、带监督）：对每个注意力头、每一层各训一个线性逻辑探针 p_θ(x) = sigmoid(⟨θ, x⟩)。探针输入是把「问题 + 答案」拼接后、最后一个 token 处该头的输出激活（即注意力之后、输出投影之前的值）；标签来自 TruthfulQA 重组出的 5,918 个 QA 对的真/假标注。每个头的探针数据按 4:1 分训练/验证集，验证集探针精度即该头「与真实相关」的度量。结果（§3.2、图 2）：多数头只有随机水平，但信息集中在早—中层、每层有少数头突出；最佳单头是 LLaMA-7B 第 14 层第 18 头，验证精度 83.3%。把全部头拼接训一个探针也只有 84.4%（§5.5）——「真实」信息高度集中于少数头。第二探针（与第一方向正交约束下再训）仍高于随机，说明「真」住在一个子空间而非单一方向（§3.2、图 2B）。干预形式：推理时只对探针精度 top-K 的头施加平移——被选头的输出加上 α·σ·θ，其中 θ 是该头的单位化「真实方向」，σ 是激活沿该方向在训练+验证集上的标准差——即平移量以每头自身激活尺度归一化，α 是「多少个标准差」为单位的强度；未入选的头方向恒为 0。干预在每个自回归步、对每个新 token 重复施加，与解码算法正交（§3.3）。方向的三种取法（§4.2、表 3）：(1) 探针权重方向——分离超平面的法向，等价于对头激活做一步梯度上升、最大化被探针判为真实的概率；(2) 质心均值平移（mass mean shift）——由假激活均值指向真激活均值的向量，主实验采用；(3) CCS 方向——无标签、仅用成对一致性找方向，真/假朝向需事后用标签定向。对照结论：质心平移最好且对大 α 的容忍度最高；附录 B 给出几何解释——各向异性分布下分离超平面的法向与质心连线并不一致，与真最相关的方向未必是因果上最能引出真实生成的方向。超参与数据量：K 与 α 无理论最优、靠扫参；在各 5% 问题作训练/验证的协议下选出 K = 48、α = 15（§4.3、图 4）；但在 2 折交叉验证协议下质心平移的最优 α 是 20（表 3、表 5）——引用 α 数值必须带协议。作者在相关工作中自述 ITI 最少用 40 个样本即可定位头与方向（§2）；主实验至多用 10% 的 TruthfulQA（81 个问题）做超参选择，方向估计用 2 折交叉验证保证不见测试样本（附录 C）。α 的取舍作者明言交由使用方按需求试错：极端厌恶不真实回答就调大，同时要顾有用性就调小（§3.3）。计算开销：无论干预多少头，每层只需往残差流加一个常数向量，等价于离线改写输出投影的 bias 项（式 3），开销近零（§5.2）。这是它与 RLHF/SFT 的核心卖点对比：无标注大军、无梯度更新。

## 实验设置

模型为 LLaMA-7B 及其指令微调衍生 Alpaca、Vicuna（均为 7B）。主基准为 TruthfulQA 生成轨（贪心自回归生成）+ 多选轨。生成轨主指标为 true*informative（真实率 × 信息量率之积，防「一律拒答」刷真实率），标注由两个微调 GPT-3-13B（GPT-judge）完成，是该基准的标准做法；作者另对 LLaMA-7B 有/无 ITI 的答案做过人工标注校验（§4.1）。另报 true 率、MC 精度，以及度量行为漂移的 CE（Open Web Text 子集上的预训练损失）与干预前后下一 token 分布的 KL。基线：监督微调（SFT，与预训练交替以压 CE/KL）、少样本提示（FSP，50-shot 分布内提示）、指令微调模型本身；方向基线为随机方向与 CCS 方向。OOD 迁移协议：在 TruthfulQA 上学到的方向与超参原封不动、不重调（真零样本）搬到 Natural Questions（3,610 条真实搜索查询）、TriviaQA（95k）、MMLU（57 学科），前两者为闭卷多选口径、MMLU 用标准 Harness 协议（§5.3、表 4）。

## 关键数字

探针—生成鸿沟：约 40 个百分点（§1）；最佳单头探针验证精度 83.3%（第 14 层第 18 头，§3.2/图 2）；全头拼接探针 84.4%（§5.5）。表 1（5% 数据口径，LLaMA-7B）：基线 true*info 30.5 / true 31.6 / MC 25.7 / CE 2.16；+ITI → 43.5 / 49.1 / 25.9 / CE 2.48 / KL 0.40；SFT 36.1；FSP 49.5；FSP+ITI 51.4（true 53.5）。表 2（2 折，指令微调模型）：Alpaca true*info 32.5 → 65.1（摘要头条；true 32.7→66.6，MC 27.8→31.9，CE 2.56→2.92，KL 0.61）；Vicuna 51.5 → 74.0（true 55.6→88.6，MC 33.3→38.9，CE 2.63→3.36，KL 1.41）。表 3（方向对照，2 折，LLaMA-7B）：基线 30.5；随机方向（α=20）31.2——大强度随机扰动几乎无效应；CCS（α=5）33.4；探针权重方向（α=15）34.8；质心均值平移（α=20）42.3。表 4（OOD 零样本迁移，多选精度）：Natural Questions 46.6→51.3；TriviaQA 89.6→91.1；MMLU 35.71→40.16。表 5（干预位置选择，2 折）：全头不加选择（α=5）35.4；逐点（按探针系数绝对值）选择（α=15）39.2，但 CE 4.01 / KL 1.95；按头选择（α=20）42.3，CE 2.41 / KL 0.27。

## 消融说明了什么

倒 U 曲线（图 4）：true*info 随 α 先升后降——强度不足时无效应，过强时信息量崩塌。干预强度是真实存在的校准问题，不是越大越好。方向易找（图 6A）：训练集从小到大，真实性很早就平台化，且小样本学到的方向与全集方向的余弦相似度上升很快——数据效率的卖点有直接证据。权衡被量化为拒答（图 6B）：α 越大，「I have no comment」式回答越多；真实性—有用性权衡不是修辞，而是可测的拒答率曲线。稀疏选址是承重设计（表 5）：全头干预与逐点选择都到不了按头选择的效果；逐点选择在更低真实性下付出数倍 CE/KL——「头」是正确的干预粒度，干预位置的稀疏化本身就是保住其余行为的前提。而全头拼接探针精度（84.4%）仅比最佳单头（83.3%）高 1.1 个百分点，说明可干预的信息本就集中。相关 ≠ 因果（表 3 + 附录 B）：探针最优分离方向（34.8）输给质心连线方向（42.3）；且附录 B.1 给出 ITI 可行性的结构直觉——对单个头施加 20σ 的随机强扰动也几乎不改变模型的低层行为（流畅性、知识），多个头协同的小幅定向平移却能撬动高层行为倾向。单头扰动的鲁棒性是这套方法的隐含地基。增益弥散（图 5）：38 个子类中大多数都有提升，没有单一类别驱动总分，也看不出哪类问题受益最大的模式。

## 局限

作者自承（逐项可查）：(1) 「我们不主张 ITI 本身接近足以保证 LLM 给出真实答案」（§1）；(2) TruthfulQA 只覆盖「避免常见误解」这一窄义的真，向真实世界聊天场景的泛化是首要未来工作（§3.1、§6）；(3) 不对干预究竟改变了什么内部表征作机理主张——方向是相关还是因果，他们只做了部分探索（§2）；(4) GPT-judge 略高估真实率、略低估信息量（§4.1 人工校验）；(5) α 无理论指导、只能使用方试错（§3.3）；(6) 附录 B 自承：沿任一被选方向平移激活都不可避免地扭曲该空间编码的其他信息，「外科手术式干预不可能」。失败模式（原文证据）：α 过大 → 拒答激增、true*info 沿倒 U 下行（图 4、6B）；多选轨增益远小于生成轨（表 1 中 MC 仅 25.7→25.9）——干预主要改变生成倾向，对判别/排序能力几乎无作用；在已较强的 Vicuna 上 KL 达 1.41、CE +0.73，行为漂移不可忽略（表 2）。另须注意其干预是无条件、恒定的（分析推断，非原文结论）：头集与方向离线定死后，对每一个输入、每一个 token 以同一 α 施加，全程没有「当前输入是否需要干预」的判别器；其 OOD 迁移只在三个同源问答基准上验过 +1.5 到 +4.7 的小幅增益（表 4），方向跨模型、跨任务的稳定性并未建立。它的成功前提——探针精度远高于生成精度、即「正确答案已编码在内部、只需引出」——是特定于自回归语言模型与真实性这一属性的经验事实，不是一个可移植的定理。
