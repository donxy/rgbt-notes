**一句话要点**：Per-test-point adaptation via marginal entropy over augmentations.

## 点评

全名 MEMO: Test Time Robustness via Adaptation and Augmentation（NeurIPS 2022），是 TTA 谱系中假设最少的一篇：对单个测试点采样多个增广视图、最小化平均（边缘）分布的熵（同时强制置信与跨视图一致，不只是各视图熵的平均），对全部参数做一步梯度更新后在原始点上预测、逐点重置丢弃。与 Tent 的分界：Tent 是 batch 级熵、只动 BN 仿射、可在线累积；原文附录还给出锚点——batch=1 的 episodic Tent 恰等于「MEMO 去掉增广」、几乎无增益，增广是承重部件。它的适应信号纯自指且方向与折扣相反（结构分析）：无标签、无原型、无第二来源，信号全部来自被适应对象自身对同一点的多次观察，熵目标只能说「保持一致、保持自信」、说不出「这一路在说谎」；放到受损模态上，受损输入的全部增广视图同样受损，强制一致 + 求置信只会让模型更一致、更自信地使用受损证据。灾变风险有原文自证：让它在测试流上持续适应的初步实验直接退化为对任何输入以最大置信输出恒定标签，其安全性完全押在单步 + 逐点重置的协议上、方法内部无防退化机制；且逐点也非无害（多档模糊上反劣于基线）。成本是每点一次微型训练（约为单点 BN 适应的 39 倍），与检测器在视频率下的部署、以及持续性传感器故障所需的时间累积双重冲突。它在单点设定下于 ImageNet-C/R 取得 SOTA，是通用 TTA 的上限标本；TTA 的 2×2 至此完整（Tent = 分类 × batch；MEMO = 分类 × 单点全参数；MM-TTA = 3D 分割 × 跨模态伪标签；CD-Buffer = 检测 × 单模态），检测 × 多模态融合一格仍空——原因不在没人做 TTA，而在现成 TTA 的目标函数都预设「输入可信、只需让模型适应它」，与「保持模型不动、折扣受损证据」在适应对象上正好相反。

## 问题定义

全名 MEMO: Test Time Robustness via Adaptation and Augmentation。MEMO 是方法自称的缩写，展开为 Marginal Entropy Minimization with One test point（用单个测试点做边缘熵最小化）。作者定义的问题是 test time robustness（测试时鲁棒化）：给定一个已训练好的模型与单个测试输入，必须立即给出该点的预测；能否利用这一个测试点本身携带的信息，在预测前把模型临时调好。其针对的痛点是先行 TTA 方法的隐藏假设：BN 统计类方法与 Tent 需要一批乃至整个测试集才能估计统计量或做熵最小化；TTT 类方法需要专门的训练流程与辅助头。这些假设使 TTA 难以即插即用。MEMO 的问题设定因此被刻意压到最紧：对训练过程零假设（唯一要求是模型输出可微的概率分布、参数可调），对测试数据只假设能拿到当前这一个点、且可对它采样数据增广。分布偏移在本文中就是 ImageNet-C 式整图数字腐化、ImageNet-R 的风格/域偏移与 ImageNet-A 的天然难例——偏移作用于唯一的输入流，不存在第二个证据来源，全文没有模态、传感器状态或证据可靠性的概念。定位：测试时适应（TTA）谱系中假设最少的一篇——不需要改训练、不需要标签、不需要多个测试点、不需要特定架构；单模态图像分类。

## 方法细节

流程（§3、Algorithm 1）对每个测试点 x 独立执行一遍。其一，造视图：从增广函数集 A 中均匀采样 B 个增广 a_i，得到 x̃_i = a_i(x)。实验用 AugMix（选取理由：只需输入本身即可采样、多样性足；且测试增广不必与训练增广相同）。AugMix 按其原论文的设计明确排除了与 -C 基准腐化相似的变换。其二，边缘分布：把每个视图过模型，取预测分布的平均 p̄_θ(y|x) ≈ (1/B)·Σ_i p_θ(y|x̃_i)（式 (1)）——即非适应 TTA 基线所用的边缘输出分布。其三，一步适应：最小化该边缘分布的熵 ℓ(θ; x) = H(p̄_θ(·|x))（式 (2)），对全部参数 θ 做一次梯度更新（更新规则 G：ResNet 用 SGD，RVT 用 AdamW）。关键在于目标是「平均分布的熵」而非「各视图条件熵的平均」（式 (3)）：后者允许模型对每个视图各自自信地给出不同答案，前者只有当所有视图给出同一个且自信的预测时才取最小——置信与跨视图不变性被耦合在同一个标量目标里。其四，预测并丢弃：用适应后的模型在原始 x（不是增广副本）上出最终预测；下一个测试点重新从预训练参数开始（逐点独立、episodic，无跨点累积）。两个设计注记。其一，作者明言先行方法「必须小心选择适应哪些参数以避免退化解」，而 MEMO 敢于全参数适应，靠的是单步 + 逐点重置的协议把漂移关在笼子里。其二，默认与 Schneider et al. 的单点 BN 适应组合：用单个测试点估计的逐通道 BN 均值/方差按先验强度 N=16 与训练统计量混合；该组合从不有害、通常有益，但不是必需（ViT 无 BN 照样可用；WSL ResNeXt 上单点 BN 反而有害，实验中被去掉）。与 Tent 的区别须钉死：Tent 最小化的是一批真实测试点上的（条件）熵、只更新 BN 仿射参数、依赖 batch 统计，且其 online 版在整个评测流上持续累积；MEMO 用增广把单个点「合成」成一个视图集合、最小化平均分布的熵、全参数更新、逐点重置。附录 B 的表 5 给了等价性锚点：batch size=1 的 episodic Tent 恰等于「MEMO 去掉增广」，其增益在单点 BN 之上所剩无几——增广是承重部件。

## 实验设置

任务与数据：仅单模态图像分类。CIFAR-10 / CIFAR-10.1 / CIFAR-10-C（自训 ResNet-26，沿 TTT 协议用 GroupNorm，故单点 BN 不适用）；ImageNet-C（指标 mCE）、ImageNet-R、ImageNet-A（指标为错误率），模型为 torchvision 基线 ResNet-50、DeepAugment+AugMix 鲁棒 ResNet-50、MoEx+CutMix ResNet-50、RVT*-small（鲁棒 ViT），ImageNet-A 另加 ResNeXt-101 及其 WSL 预训练版（表 3）。超参纪律：只在 CIFAR-10-C / ImageNet-C 自带的 4 个验证腐化上网格搜索（学习率、步数 {1, 2}、先验强度 N），ImageNet-R/A 直接沿用、不再调。主要取值（附录 A）：ResNet-26 用 B=32、η=0.005；ResNet-50 用 B=64、η=0.00025；RVT*-small 用 AdamW、η=1e-5、weight decay 0.01、B=64；ResNeXt-101 因显存用 B=32。曾试过「边缘熵高于最大值 50% 才适应」的门控变体，验证集上略差，未采用。学习率跨架构差两个数量级（5e-3 → 2.5e-4 → 1e-5），「即插即用」仍需在带偏移的验证集上逐模型调参。对照协议对 MEMO 不利而它仍赢：BN 适应基线拿到 256 个测试点成批适应，Tent 拿 batch=64（online 版在整个评测期持续适应、episodic 版逐 batch 重置）；MEMO 严格只看 1 个点、且必须在适应后立即预测该点。

## 关键数字

总 claim（摘要与 §1）：相对标准评测精度增益 1–8%；在「只见单个测试点」设定下于 ImageNet-C、ImageNet-R 取得 SOTA，ResNet-50 类模型中于 ImageNet-A 取得 SOTA；据作者所知是第一个在 ImageNet-A 上取得正增益（1–4%）的适应方法——多点方法在 ImageNet-A 上普遍无效甚至有害。表 1（CIFAR，错误率 %）：ResNet-26 基线 9.2 / 18.4 / 22.5（CIFAR-10 / 10.1 / 10-C 平均）→ +MEMO 7.3 / 14.7 / 19.6（−2.9）；非适应 TTA 为 19.9，需要专门联合训练的 TTT 为 21.5。表 2（ImageNet：mCE / 错误率 % / 错误率 %）：基线 ResNet-50——76.7 / 63.9 / 100.0 → +MEMO 69.9（−6.8）/ 58.8（−5.1）/ 99.1（−0.9）；DeepAugment+AugMix ResNet-50——53.6 / 53.2 / 96.1 → +MEMO 49.8 / 49.2 / 94.8；MoEx+CutMix ResNet-50——74.8 / 64.5 / 91.9 → +MEMO 69.1 / 59.4 / 89.0；RVT*-small——49.4 / 52.3 / 73.9 → +MEMO 40.6（−8.8）/ 43.8（−8.5）/ 69.8（−4.1）。同表必须同时读到的反面：拿到 batch 的多点方法在 ImageNet-C/R 上仍强于 MEMO（基线 ResNet-50 上 Tent-online 的 mCE 为 54.4、BN-256 为 61.6，均优于 MEMO 的 69.9）；但它们在 ImageNet-A 上普遍回退，且在 RVT 上灾难性失败——Tent (adapt all) 使 RVT 的 ImageNet-R 错误率从 52.3 升至 74.1（+21.8），Tent-online 在 ImageNet-A 上 82.1（基线 73.9）。全参数熵适应在 batch/持续模式下的崩塌风险在此有成表读数。表 3（ImageNet-A，ResNeXt-101）：普通预训练 90.0 → +MEMO 84.3；WSL 预训练 54.9 → +MEMO 43.2（−11.7），为全表最佳，显示其与大规模预训练有协同。逐腐化读数（附录 C 表 7–11，CIFAR-10-C 全部 15 类腐化 × 5 档）：MEMO 在绝大多数格子上优于基线与 TTA，如 5 档高斯噪声 48.4 → 43.5、脉冲噪声 50.3 → 43.3、玻璃模糊 47.7 → 44.4。少见的负例集中在 5 档模糊族：defocus blur 基线 24.1 → MEMO 26.4、motion blur 24.5 → 25.1、zoom blur 24.1 → 25.0（TTA 同样回退且更差）——增广式适应并非逐点无害。ImageNet-C 的逐腐化明细不在正文（仅补充 CSV），未读到。成本（§4.2、图 3）：ResNet-50、4 CPU + TITAN RTX、增广未并行实现下，单点耗时——单点 BN 适应 0.0252 s；B=64 时 TTA 0.7742 s、MEMO 0.9746 s（约为单点 BN 的 39 倍）；B=4 时降至 0.0631 / 0.1037 s。大 B 时墙钟主要耗在增广计算本身。

## 消融说明了什么

目标消融（表 4）：把边缘熵换成只有不变性的成对交叉熵（PCE，各视图预测两两对齐、不求置信）或只有置信的平均条件熵（CE，≈ 在增广单点上做 episodic Tent），两者在 CIFAR 三集上均为 20.0（MEMO 19.6），在 RVT 的 ImageNet-C/R 上亦逊于 MEMO（CE：41.2 / 44.2 vs 40.6 / 43.8；仅 ImageNet-A 上 CE 以 69.7 微胜 69.8）。结论：置信与不变性两个信号缺一不可，但边缘熵的边际优势不大、贵在一致。增广必要性（表 5）：batch=1 的 episodic Tent（即去掉增广的 MEMO）在单点 BN 之上几乎无增益（RVT mCE 47.9 vs 单点 BN 的 48.0，MEMO 为 40.6）——对原始单点直接做熵最小化近乎惰性，增广视图集合是学习信号的来源本身。增广种类（表 6）：换成标准随机裁剪+翻转，在干净 CIFAR-10 与 10.1 上几乎不差，但在 CIFAR-10-C 上回退（20.2 vs 19.6）——偏移越重，越需要 AugMix 级的重增广。视图数 B（图 3）：B ∈ {1,…,128} 扫描下，B=4–8 已能拿到显著增益，精度–成本折中可行；主实验的 B=32/64 是偏精度一端的选择。

## 局限

其一，成本结构：每个测试点都要付 B 个视图的前向 + 全参数的一步反向，推理从「一次前向」变成「每点一次微型训练」。作者自己在 §5 把效率列为首要开放问题，并设想用置信度门控决定何时适应——即承认默认形态对高吞吐部署不友好。其二，安全性完全押在协议上：方法本身没有任何防退化机制——单步、逐点重置、边缘（而非条件）熵三者共同把漂移限制住。作者在 §5 披露：让 MEMO 在测试流上持续适应的初步实验直接退化为「对任何输入都以最大置信输出恒定标签」；修复只停留在设想（只适应 BN 参数、或向预训练模型正则化）。逐点情形下也没有任何逐点保证：附录 C 中 5 档模糊族的负格子说明，适应完全可能把某个点的预测改坏，且无信号提示。其三，熵目标是求置信、不是求正确：若模型在某点上自信地错且各视图一致，边缘熵已接近最小、无纠正信号；若各视图在错误类别上不一致，适应只保证收敛到某个一致答案，不保证是真答案。整个回路中没有标签、原型、第二模态等任何外部参照——适应信号全部来自被适应对象自身对同一点的多次观察（自指结构）。其四，设定边界：单一输入流、单标签分类、目标定义在一个全局类别分布上。输入可靠性、传感器健康、多证据源仲裁等概念在形式化中不存在；评测偏移均为整图、保标签的数字腐化/风格偏移，没有「输入本身是受损证据、需要被折扣」的情形。
