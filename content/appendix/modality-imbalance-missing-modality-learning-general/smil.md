**一句话要点**：Bayesian meta-learning for severely (≤90%) missing modalities.

## 点评

全名 SMIL: Multimodal Learning with Severely Missing Modality（AAAI 2021）。「severely」指缺失推进到训练数据本身——多达 90% 的训练样本只有一个模态，训练/测试/两者缺失用同一模型处理；但施加是构造性的：一个模态恒 100% 在场、另一模态按数据集级比例留存（方向单向），且仍需约 10% 完整样本聚先验与做元测试；参照系锚定完整模态上限（与缺失模态综述同设定）。重构机制不是直接生成、是先验加权和：先对完整样本的缺失模态特征聚类得先验库，重构网络只预测先验权重的高斯方差、重构特征是先验的加权混合——群体猜测而非个体证据，重构保真度本身从未被测量；配套的贝叶斯特征扰动正规化才是消融中的承重件。融合本体是最朴素的拼接 + FC，对「这一路是真的还是重构的」无感知、无差别。「损坏但存在」评测核实为零：失效模型只有二值缺席一档。补缺失两派的分野：SMIL 是重构派（合成缺失者的近似特征、当作真实证据送进融合），ShaSpec 是替代派（不猜缺失模态、用幸存模态 shared 表征的均值顶替）；ShaSpec 沿用其协议/编码器/基准并胜出——纯缺失端上替代派以更低复杂度拿到不低于重构派的结果。重构式补位在 damaged 端有三条原理困难（结构推断）：在场标志使重构通路永不触发、损坏特征全额入场；若人为判为缺失并重构，干净数据上聚出的先验会把残存真实信号一并换成无法校验的群体猜测；若损坏的恰是条件模态，重构继承损坏却穿着另一模态的外衣入场、更难察觉。

## 问题定义

全名 SMIL: Multimodal Learning with Severely Missing Modality。既有缺失模态工作只处理两种较弱的设定：测试时缺失、训练数据未配对；训练与测试都假设模态完整则是更普遍的默认（图 1a–c）。SMIL 研究图 1d 的设定：训练、测试或两者同时出现模态缺失，且缺失是「严重」的——训练样本中多达 90% 只有一个模态。形式化只考虑双模态：数据集分为完整样本集 Df 与缺一模态的样本集 Dm；目标是用两者联合训练，使性能「尽可能接近在完整模态数据上训练的模型」——参照系从一开始就锚定在完整模态上限（Upper-Bound），不是幸存子集的下限。两个设计目标：灵活性（一个统一模型处理训练缺失、测试缺失、两者缺失，测试时完整/不完整输入靠开关重构网络切换）与效率（在完整样本极稀缺时仍学得动——重构网络只靠少量完整样本训练必然带偏，须有机制对冲这种偏差）。失效模型严格是二值的：某模态对某样本整体不存在。缺失的施加方式是构造性的——实验中把一个模态在数据集层面按比例 η 留存（η = 保留该模态的样本数 / 总样本数），另一个模态恒 100% 在场；缺失方向是单向的（只有文本/音频可缺，图像永不缺）。定位是缺失模态学习的「重构派」源头工作之一——首次把问题设定推进到训练数据本身严重不完整（完整样本可低至 10%），且训练/测试/两者缺失用同一模型统一处理。

## 方法细节

三个网络装进一个改造过的 MAML 框架（图 2、Algorithm 1）：主网络 fθ、重构网络 fφc、正规化网络 fφr，后两者合称 ψ，用贝叶斯元学习（变分下界 + KL + 蒙特卡洛采样）联合优化：内循环在不完整数据 Dm 上元训练主网络，外循环在完整数据 Df 上元测试并元更新 {θ, ψ}。缺失模态重构（φc）——不是直接生成，是先验加权和。直接由可用模态生成缺失模态特征在完整样本稀缺时不可行，SMIL 借鉴 ShapeMask 式先验：先对完整样本的缺失模态特征做 K-means（或 PCA）聚类，得到一组模态先验 M；φc 不生成特征本身，只预测先验权重 ω 的分布参数——ω ~ N(I, σ)，σ 由可用模态预测；重构特征是先验的随机加权组合 ⟨ω, M⟩。重构目标是在完整样本上最大化重构特征的条件对数似然。随机性（采样 ω）被作者视为刻意引入的不确定性建模。不确定性引导的特征正规化（φr）——处理重构偏差。φr 逐层以浅层特征为输入输出高斯 (µ, σ)，采样正规化量 r，正规化特征为原特征与 Softplus(r) 的加或乘。其作用是扰动潜特征、使单模态嵌入逼近完整模态嵌入，压低「用带偏重构特征直接训练」对效率的损害。本质上是一个学出来的、带不确定性的特征扰动器，不是质量估计器——它不评估任何模态的可信度，只平滑嵌入空间。测试时形态：同一模型两种跑法——输入完整则重构网络关闭、两路真实特征直接拼接融合；输入缺一路则开启 φc，用先验加权和补齐缺失槽位再走同一条融合通路（图 2b/2c）。融合算子本身是最朴素的特征拼接 + FC，无任何权重、门控或逐模态折扣——补位发生在融合之前，融合层对「这一路是真的还是重构的」无感知、无差别对待。

## 实验设置

全部是分类任务，无检测、无 RGB-T。MM-IMDb（图像 + 文本，电影类型多标签分类，25,956 部、23 类），指标 F1 Samples / F1 Micro（表 2）。CMU-MOSI（视频情感二分类；原数据三模态，实验只用图像 + 文本两路），指标 Accuracy / F1（表 1）。avMNIST（MNIST 图像 + 口语数字音频的 MFCC 特征，1,500 样本，70/30 划分），指标 Accuracy（图 4，无数值表）。缺失协议：图像恒 100% 在场，文本（或音频）按 η ∈ {10%, 20%, 100%} 留存（avMNIST 的图 4 另扫到 η = 5%）；η 是数据集级比例、方向单向、缺失样本固定，不是逐样本随机组合枚举。基线：Lower-Bound（仅单模态训练）、Upper-Bound（全模态全数据训练）、AE（先用完整样本训自编码器填充、再训分类器）、GAN（同 AE 的填充流水线）、MVAE（只在 100% 下以线性评估协议参加）。骨干均为小网络（FC/LSTM/LeNet-5 级别）。

## 关键数字

CMU-MOSI（表 1）：SMIL 的 Accuracy 在 η=10% / 20% 为 60.7 / 63.3，F1 为 58.0 / 62.5；AE 为 56.4 / 60.4、GAN 为 56.5 / 60.6。值得注意的对照：MVAE 在 η=100%（无缺失）下 Acc 只有 58.5，低于 SMIL 在 η=10% 严重缺失下的 60.7——这是作者「不必要在严重缺失下训 MVAE」论点的依据。Upper-Bound（100%）Acc 71.0、Lower-Bound 44.8，SMIL 距上限仍有约 8–10 个点。MM-IMDb（表 2）：SMIL 的 F1 Samples 在 η=10% / 20% 为 49.2 / 54.1，F1 Micro 49.5 / 54.6；AE 44.5 / 50.9、GAN 45.0 / 51.1；Lower-Bound F1 Samples 47.6、Upper-Bound 61.7。作者报告的规律：缺失越严重，SMIL 相对生成式基线的优势越大（MOSI 上 η=20% 时领先 AE/GAN 约 5 个点，η=10% 时扩至约 7.6 / 7.4 个点）。avMNIST（图 4，正文文字报告，无数值表）：模式 1（训练不完整、测试仅图像）——η=20% 时 SMIL 比生成式方法高 6.7%、比 Lower-Bound 高 3.3%；η=5% 极端档仍比 Lower-Bound 高 1.10%。模式 2（训练不完整、测试全模态）——SMIL 比 Lower-Bound 高 4.3%、比 AE/GAN 高 2.1%。测试形态从双模态切到单模态时，AE/GAN 掉 5.6 个点、SMIL 只掉 1.0 个点——「统一模型」主张的主要证据在此。逐类型现象（图 3）：文本模态对 Family、Animation 两类反而轻微有害（作者归因于两类之间重叠大、文本强化了共享知识）——一处顺带记录的模态负迁移，未展开。

## 消融说明了什么

消融在 MM-IMDb 上做（表 3，F1 Samples，η=10% / 20%）：完整 SMIL 0.492 / 0.541。去 K-means 先验、改为重构网络直接生成特征（w/o K-means）：0.482 / 0.535——先验加权和优于直接生成，但差距只有约 1 个点；「重构派内部」的关键设计并非增益大头。去特征正规化（w/o Regularization）：0.469 / 0.521——η=10% 时掉 2.3 个点，是单项最大跌幅，说明在严重缺失下，对冲重构偏差的正规化比对冲「重构什么」更承重；增益主要来自让主网络在被扰动的、近似完整模态的嵌入上训练。去贝叶斯推断：固定高斯 N(0, I) 为 0.475 / 0.495，确定性（去采样）为 0.474 / 0.527——随机性与学出来的分布参数各值约 1–2 个点，但都不是数量级效应。总体读法：SMIL 的优势是「先验重构 + 正规化 + 元学习排程」的合成效应，没有任何单项机制值大头；且全部消融只在 η ∈ {10%, 20%} 两档上做，没有 η 连续扫描曲线，也没有「哪一路缺失」的方向消融（协议本身就是单向的）。

## 局限

其一，失效模型只有二值缺席一个档。全文无任何「在场但损坏」的评测：无注噪、无模糊、无传感器故障、无分布偏移实验；正文中的「noise」只指 ω 与 r 的高斯采样（模型内部随机性），与输入损坏无关。损坏在 SMIL 的词汇与开关逻辑中都不存在——重构网络开不开由「缺没缺」这个二值事实决定，没有第三种状态的位置。其二，缺失方向单向、比例构造化。三个数据集都把图像设为恒在场、只缺文本/音频；缺失按数据集级比例人工施加在原本完整的数据上。真实部署中哪一路会缺、缺多少、以什么时间结构缺，都不在其协议覆盖内；三模态以上的组合枚举也未触及（形式化只写双模态）。其三，重构保真度无从核查。全部证据是下游分类指标；重构特征与真实缺失特征的距离、逐样本重构失败案例、先验个数（K-means 的 K）敏感性均未报告。重构特征是先验的凸组合式混合，本质上是「这一类样本的该模态特征大概长这样」的群体猜测，个体证据在重构中不可恢复——作者对此不避讳（这正是设计取舍），但引用时不能把 SMIL 的数字读作「缺失信息被找回来了」。其四，参照系是上限而非下限。目标函数与叙事都是逼近 Upper-Bound；唯一的单模态对照 Lower-Bound 是单独训练的模型。在 avMNIST 模式 1 中 SMIL 确实高于 Lower-Bound（缺失端下重构补位净正），但这回答的是「补位 vs 不补」而非「融合 vs 丢弃在场证据」，两个问题不可互替。其五，规模与任务都很轻：小骨干、分类、千级到万级样本；元学习内外循环的计算开销未与基线做同预算对比。
