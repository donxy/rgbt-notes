**一句话要点**：Prototypes accelerate the slow-learning modality; entropy regularizer vs dominant modality.

## 点评

再平衡作用于损失构成、不是学习率也不是梯度幅值：原型 = 逐模态逐类表示质心；原型交叉熵只给慢学模态开启、其梯度不经融合头（方向独立于主导模态），是对其自家诊断（病理在梯度方向污染而非幅值）的直接回应；原型熵正则只在训练早期惩罚主导模态。推理期什么都不剩：无原型、无权重、无门控，融合算子原样消费两路。其失衡度量 ρ 是自指信号的又一标本——用每个模态自身表示 + 自身原型的非参数分类器给该模态打分再取比值，两模态分数不在同一几何/标度上，且训练早期（压制形成期）度量最不可靠；作者自家消融记录了代价（原型子集降到 1% 时结果反低于朴素基线）。对下限问题有成文的动机侧证据（分类口径）：CG-MNIST 上朴素融合低于两个单模态中的任何一个，PMR 全力再平衡后仍远低于最佳单模态（78.5 vs 99.3）——其单色模态是「训练强相关、验证弱相关」的捷径模态，与「损坏模态在训练分布内看似无害」结构同型；成文证明训练期再平衡无法恢复「丢弃该模态」的下限，因为这类方法的架构里根本没有丢弃这个动作。缺失/损坏评测严格为零：其 imbalance 是训练期学习速度差（需标签与类原型），与测试时「这一路现在还可不可信」不是同一个量。谱系位置：OGM-GE（梯度幅值）→ PMR（损失级方向独立通道）→ MMPareto（帕累托梯度合成）→ ReconBoost（交替更新），全部解法限于训练期。

## 问题定义

针对的是联合训练中的模态失衡（modality imbalance）：不同模态过拟合与收敛速度不同，在统一优化目标下，主导模态在梯度更新中压制慢学模态，使每个模态都远离各自单模态训练可达的上限，融合结果甚至可以劣于最佳单模态（§1、§2.1）。作者自己的增量诊断（§3，CREMA-D，图 2）分三步：图 2a——音频模态的训练表现与融合表现几乎重合、视觉模态远逊，融合梯度实际由表现与融合更接近的强模态主导，视觉被严重压制。图 2b——把 OGM-GE 的思路反过来用（直接放大慢模态视觉的梯度幅值），验证精度只小幅改善，不如压低强模态梯度的 OGM-GE。图 2c（本文立论核心）——逐模态用各自单模态 CE 算出的「应然梯度方向」与多模态实际梯度方向之间的夹角在训练中急剧增大（始终保持锐角）。即主导模态不只压制慢模态的梯度幅值/学习速度，还持续污染其更新方向；沿被污染的方向单纯调幅值，治标不治本。对既有调制工作的两点批评：调制信号取自融合输出，而融合输出本身被强模态主导（信号先天偏袒强者）；且已有方法或引入额外结构、或受融合方式限制（如 OGM-GE 的贡献度量需要分类头 logits 可按模态分解）。定位是通用多模态学习（以音视频为主）的训练期模态失衡调制策略——一个与融合方式、模型结构无关的损失级插件；非检测、非 RGB-T、无任何测试期机制。

## 方法细节

PMR 只动损失构成，不动优化器、不做梯度后处理，由三部分组成。(1) 逐模态原型与非参数分类器。原型 = 每个模态各自表示空间中每一类的质心；为省算力并稳定，用训练集 1/10 的子集计算、逐 epoch 以动量 ε 更新。注意原型由模型当前正在训练的编码器特征算出。分类器为非参数式：样本表示到各原型取欧氏距离、负距离过 softmax 得类别概率——绕开了「需要可分解参数分类头」的限制，这是它敢称与融合方式无关的前提。(2) 失衡比 ρ_t（借鉴 OGM-GE 的比值思想）。每个 step 取当前 batch 内两模态原型分类器在真值类上的概率之和作比，实时度量两模态的学习状态差距。该度量完全建立在各模态自身的表示与自身原型之上（自指性质见「局限」）。(3) PCE 损失——给慢模态开一条方向独立的通道。逐模态的原型交叉熵：以距离 softmax 为预测的普通 CE，几何上把样本表示拉向本类原型、推离异类原型（强化类内聚类）。关键性质：模态 k 的 PCE 梯度只流经模态 k 自身的表示与原型，不经过融合头，因此主导模态无法扰动这条梯度的方向——直接回应图 2c 的诊断。总加速损失 = 融合 CE + α·β·模态 0 的 PCE + α·γ·模态 1 的 PCE，其中 β/γ 由 ρ_t 分段开关：ρ_t<1（模态 0 慢）时 β=clip(0, 1/ρ_t−1, 1)、γ=0；ρ_t≥1 时反之。任一时刻只有慢学模态的 PCE 被打开（权重为截断到 [0,1] 的失衡程度），快模态维持原始融合 CE 不变。α 按数据集取 1 或 2。(4) PER——只在早期拖住主导模态。原型熵正则：对主导模态的原型距离分布做熵最大化（总损失中减 μ·熵），系数与 PCE 交叉对应（β/γ 乘到对侧模态），语义是惩罚主导模态过早收敛、减轻其早期压制。只在前 E_r 个 epoch 施加；μ 取 1e-2 或 1e-3 量级的小值。整体流程（Algorithm 1）：每 epoch 先用子集前向更新原型，再逐 batch 计算 ρ_t、组装总损失更新模型。推理期形态：PMR 是纯训练策略，推理时模型就是原封不动的基座多模态网络——没有原型、没有 ρ_t、没有任何逐模态权重或门控，融合算子（concat / summation / FiLM / gated / MMTM / CentralNet 等）原样消费两路输入，零额外推理成本，也零推理期适应能力。

## 实验设置

任务为多模态分类为主，外加一个事件定位迁移实验；无检测、无分割。数据集：CREMA-D（音视频情感识别，6 类，7442 条片段，6698 训练 / 744 测试）；AVE（音视频事件定位数据集，作者取带定位标注的片段构造 28 类分类集，4143 个 10 秒视频）；CG-MNIST（Colored-and-gray MNIST 合成集，60000 训练 / 10000 验证：单色图与数字标签在训练集强颜色相关、在验证集弱相关——人为植入的捷径模态）。模态记号：CREMA-D/AVE 中 modal1=音频、modal2=视觉；CG-MNIST 中 modal1=灰度图、modal2=单色（彩色）图。编码器与输入：CREMA-D/AVE 用 ResNet18、输出 512 维表示；音频转频谱图（AVE 257×1004、CREMA-D 257×299），视觉随机抽帧（CREMA-D 3 帧、AVE 4 帧）；CG-MNIST 用 4 层卷积 + 平均池化的小编码器。训练：SGD（动量 0.9、weight decay 1e-4），学习率 1e-3 衰减至 1e-4，batch 64，单张 RTX 3090；原型子集为训练集 1/10。融合基座：concatenation、summation（晚期融合），FiLM、gated（中间融合）；另在 MMTM、CentralNet（中间融合，表 3）与 AVEL 任务的 concat、DMRN（表 4）上验证通用性。对比的调制策略（表 2）：Modality-Drop、Gradient-Blending、OGM-GE。

## 关键数字

单模态基线（表 1，Acc）：CREMA-D 音频 54.4 / 视觉 58.0；AVE 音频 62.1 / 视觉 31.0；CG-MNIST 灰度 99.3 / 单色 60.4——三组数据的强弱格局各不相同（AVE 中视觉是压倒性弱模态，CG-MNIST 中单色是带捷径偏置的弱模态）。朴素融合的负融合实例（表 1）：CREMA-D 上 concat 53.2、summation 52.9 均低于视觉单模 58.0；CG-MNIST 上四种朴素融合为 58.4–60.0，不仅远低于灰度单模 99.3，concat（58.4）甚至低于单色单模 60.4——联合训练被颜色捷径劫持，是全文最醒目的一组数。加 PMR 后（表 1）：CREMA-D concat 53.2→61.1、summation 52.9→59.4、FiLM 57.2→61.8、gated 58.4→59.9；AVE concat 65.4→67.1、summation 65.1→68.1、FiLM 64.4→66.4、gated 63.5→62.7（全部实验中唯一回退）；CG-MNIST concat 58.4→77.2、summation 59.1→78.5、FiLM 60.0→76.3、gated 59.8→68.7。须注意：CG-MNIST 上 PMR 后融合（最高 78.5）仍远低于灰度单模 99.3——再平衡大幅收窄但未消除「融合劣于最佳单模态」的缺口。与其他调制策略对比（表 2）：CREMA-D concat——naive 53.2 / Modality-Drop 55.8 / Grad-Blending 56.7 / OGM-GE 57.7 / PMR w/o PER 60.3 / PMR 61.1；FiLM——57.2 / 58.3 / 58.7 / 58.0 / 61.3 / 61.8。AVE concat——65.4 / 66.4 / 65.5 / 65.9 / 67.2（w/o PER）/ 67.1（PMR）；FiLM——64.4 / 63.9 / 65.2 / 65.1 / 65.6 / 66.4。PMR 在所列对比中整体最佳。中间融合与跨任务（表 3、表 4）：MMTM 在 CREMA-D 51.6→55.1、CG-MNIST 71.4→74.2；CentralNet 50.2→52.9、69.3→72.1；AVE 事件定位 concat 72.7→74.3、DMRN 73.1→74.2。原型子集规模（表 5，concat）：1% 时 CREMA-D 54.1、AVE 62.1——AVE 上低于朴素基线 65.4；5% 时 58.4 / 65.8；10% 时 61.1 / 67.1；50% 时 61.2 / 67.7；100% 时 61.5 / 67.3。10% 以上趋稳。优化器通用性（表 6，CREMA-D / AVE）：SGD 53.2 / 65.4 → 61.1 / 67.1；AdaGrad 58.8 / 65.1 → 61.5 / 66.2；Adam 59.8 / 64.4 → 65.3 / 66.5（后者为加 PMR）。

## 消融说明了什么

PCE 是增益主体，PER 只是小幅附加（表 2）：PMR w/o PER 已拿走绝大部分提升（如 CREMA-D concat 60.3 对全 PMR 的 61.1、FiLM 61.3 对 61.8）；PER 的边际贡献约 +0.8 或持平，且非单调——AVE concat 上加 PER 反而 −0.1（67.2→67.1）。「防止强模态过早收敛」这一半机制，实证支撑明显弱于「给慢模态开独立通道」那一半。分支级证据与设计自洽（图 4，CREMA-D + concat）：朴素多模态模型内部的视觉分支精度远低于单独训练的视觉模型（慢模态在联合训练中被废掉的一手曲线证据），音频分支则与单模音频接近；加 PMR 后音频分支几乎不动、视觉分支显著回升——正是「只刺激慢者」的预期形态；图 4c 中失衡比 ρ 随训练下降，显示失衡被缓解而非仅最终精度受益。Acc 对照是立论消融（图 2b）：单纯放大慢模态梯度幅值效果有限，与图 2c 的夹角证据合起来支撑全文的核心判断——病理主要在梯度方向被污染，不在幅值。这也是 PMR 与 OGM-GE 一族分道扬镳的依据。度量本身的风险被自家消融暴露（表 5）：原型子集降到 1% 时 AVE 结果劣于基线——ρ_t 与原型都依赖对当前表示的抽样估计，估计有偏时调制会把模型往错误方向推。这是其自指度量（见下）在实验层面的直接代价记录。

## 局限

其一，问题域与评测面：全部证据来自完整模态、监督分类（情感/事件/合成数字）与一个事件定位迁移；失衡的定义是训练期学习速度差，与传感器状态无关。模态缺失、模态损坏、噪声/故障注入、测试时分布偏移——一概未评测，机制上也无对应物：ρ_t 需要真值标签与训练分布，推理期不存在；文中被对比的 Modality-Drop 是训练正则，不是缺失评测。换言之，它对「某一路在部署时坏掉」这一情形既无实验也无机制发言权。其二，度量自指（本篇最值得记的一点）：ρ_t 用每个模态自身当前表示 + 自身原型构成的分类器给该模态打分，再取比值。两点结构性含混：(i) 两个模态的分数产生于各自的表示几何，类内聚程度本就因模态而异，「分数低」混杂了「学得慢」与「该模态表示空间天然难聚类」两种成因，比值没有共同标度；(ii) 原型与分数都来自正在被训练的编码器，训练早期表示近乎随机、原型漂移，度量在最需要它的阶段（早期压制形成期）最不可靠。作者以动量更新原型、PER 只加早期等方式缓解，但全文没有把 ρ_t 与真实单模态验证精度做对照校准的实验。其三，增益边界：CG-MNIST 上全力再平衡后融合（78.5）仍远低于最佳单模态（99.3）。当一个模态是系统性捷径（训练分布内强相关、部署分布下失效）时，「拉起慢模态 + 放慢强模态」的训练期再平衡在原理上等价不了「丢弃有害模态」——而 PMR 的框架里没有任何丢弃/降权模态的选项，无论训练期还是推理期。其四，成本与适用面：每 epoch 需一次子集前向算原型（作者自承这是主要额外开销）；推导与实验均为双模态，多模态情形未实验；全部实验为分类式任务，无检测/分割/RGB-T 证据。
